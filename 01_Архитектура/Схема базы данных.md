# Схема базы данных

## Подтверждённый уровень

Полная схема таблиц в `baza` не хранится. Здесь фиксируется только подтверждённая модель данных верхнего уровня.

## Что известно

- PostgreSQL — primary DB для control/users/config;
- часть legacy/runtime state остаётся вне PostgreSQL;
- Google Sheets являются внешним owner-scoped storage-контуром, но не заменяют primary DB.

## Слои

- PostgreSQL:
  - `control_*`
  - `users`
  - `tenant_memberships`
  - `funnels`
  - `traffic_hub` SQLAlchemy-модели
- Redis:
  - queue
  - progress
  - stop flags
  - status events
- legacy SQLite/runtime:
  - `leads`
  - `send_history`
  - `invite_history`
  - `retry_queue`
  - `run_log`
  - `app_log`
  - `control_sync_queue`
