# Ветки и git-flow

## Подтверждено

- wiki repo работает от ветки `main`;
- live server repo `TrafficHub` тоже читается как `main...origin/main`.

## Практика

- wiki-изменения фиксировать обычными осмысленными commit-ами;
- не считать wiki changelog-ом: изменять её как инженерную карту системы;
- при runtime/debug-изменениях отдельно сверять, не устарели ли страницы архитектуры, эксплуатации и отладки.
