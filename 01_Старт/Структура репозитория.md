# Структура репозитория

## Live source repo

- `/root/TrafficHub`

## Ключевые зоны

- `api/*` — web/dashboard/auth/ws слой
- `traffic_hub/*` — embedded API, worker, queue/runtime слой
- `services/*`, `modules/*`, `utils/*` — legacy и cross-cutting логика
- `AccountManager/*` — отдельный product contour внутри общего repo
- `tests/*` — regression и contract tests
- `deploy/*` — infra artifacts
