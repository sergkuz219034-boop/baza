# Единая База

## Главный вход

- единственная основная wiki этого vault: [[README|Project Wiki]]
- всё, что не является её каноническим содержимым, вынесено в [[raw/legacy-vault/11_Операционный контур/README|11_Операционный контур]]

`Project Wiki` является единственной основной Obsidian wiki для проекта и разработки. Остальные разделы vault, старые локальные wiki и source workspaces считаются вспомогательными источниками или архивом.

Старые корни и тяжёлые экспорты вынесены из корня в [[raw/legacy-vault/11_Операционный контур/08 Архив/README|архив]].

## Быстрый старт

1. Для `TrafficHub` открывай [[README|Project Wiki]].
2. Для глубокого инженерного архива внутри той же wiki открывай `raw/docs/TrafficHub-obsidian`.
3. Для вакансий, диалогов, обучения и прочих рабочих данных открывай [[raw/legacy-vault/11_Операционный контур/README|11_Операционный контур]].

- `00_...10_` в корне — канонические разделы единственной основной wiki по `TrafficHub`
- `raw/docs/TrafficHub-obsidian` — полный imported engineering archive
- `raw/legacy-vault/01 Проекты` — вспомогательный source/archive layer для project notes
- `raw/legacy-vault/11_Операционный контур` — вакансии, диалоги, обучение, архив, система и прочие не-проектные материалы

## Простые правила

- неясно куда класть -> `00 Входящие`
- есть конкретный результат -> `01 Проекты`
- это постоянная операционка -> `02 Работа`
- это обучение и полезные материалы -> `03 Обучение`
- это переписки и сценарии -> `07 Диалоги`
- это не нужно в активной работе -> `08 Архив`
