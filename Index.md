## Быстрый старт

1. Все новые мысли сначала кидай в [[00 Входящие/README|00 Входящие]].
2. Для работы по вакансиям открывай [[99 Вакансии/Vacancy_Matrix|Матрицу вакансий]].
3. Для переписок используй [[07 Диалоги/Chat_Template|Шаблон чата]] и [[02 Работа/Knowledge_Base/Scripts|Скрипты]].
4. Для текущих задач смотри [[06 План/README|раздел планов]].

## Простые правила

- неясно куда класть -> `00 Входящие`
- есть конкретный результат -> `01 Проекты`
- это постоянная операционка -> `02 Работа`
- это обучение и полезные материалы -> `03 Обучение`
- это переписки и сценарии -> `07 Диалоги`
- это не нужно в активной работе -> `08 Архив`
