# Wiki TrafficHub

Эта папка — локальная Obsidian wiki проекта TrafficHub/TrafServer.

Источник истины по продукту: live-код, runtime, БД, env, контейнеры, логи и серверный репозиторий `/root/TrafficHub`. Wiki фиксирует подтверждённые знания и рабочие выводы, но не заменяет проверку по коду и runtime.

## Структура

- `00_Главное` — входные страницы, обзор, dashboard, быстрый старт.
- `01_Правила` — правила работы, workflow Codex, плейбуки, архитектурные решения.
- `02_Код` — архитектура, backend/frontend, БД, сущности, эксплуатация, тестирование.
- `03_Ошибки` — расследования, активные и решённые баги, постмортемы, debug-рецепты.
- `04_План` — roadmap, технический долг, идеи, changelog, сырьевые материалы.

## Рабочий контур

1. Для разработки и дебага сначала открыть workflow и relevant playbook.
2. Код TrafficHub читать, менять, тестировать и коммитить только на live-сервере в `/root/TrafficHub`.
3. Локальная wiki обновляется после подтверждения фактов по коду/runtime.
4. Новые баги и проверки фиксируются в `03_Ошибки/Расследования`.
5. Повторяемые знания выносятся в `01_Правила` или `02_Код`.
