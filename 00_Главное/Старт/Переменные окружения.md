# Переменные окружения

## Подтверждённые runtime-маркеры

- `DATABASE_URL`
- `REDIS_URL`
- `CONTROL_PG_LEGACY_IMPORT=false`
- `WORKER_MAX_PARALLEL_OWNERS=2`
- `AUTOLEAD_RUNTIME_LOGS_BACKEND=postgres`
- `AUTOLEAD_RUNTIME_DELIVERY_BACKEND=postgres`
- `AUTOLEAD_RUNTIME_LEADS_BACKEND=postgres`
- `AUTOLEAD_RUNTIME_AUTOFIT_BACKEND=postgres`
- `AUTOLEAD_RUNTIME_INVITES_BACKEND=postgres`
- `AUTOLEAD_RUNTIME_CONTROL_SYNC_BACKEND=postgres`

## Что важно

- env нельзя описывать по памяти или старым `.env`, если это не подтверждено live;
- для продуктовых гипотез сверять env с compose/runtime и с кодом чтения конфигурации.
- при этих флагах active runtime надо считать PostgreSQL-first даже если рядом на диске существует `autolead.db`;
- `CONTROL_PG_LEGACY_IMPORT=false` не равен полному отсутствию `control.db`, а только выключает legacy import path control-контура.
