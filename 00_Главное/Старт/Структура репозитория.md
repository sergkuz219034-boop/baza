## Ключевые зоны

- `api/`, `services/`, `modules/`, `utils/` — Autolead dashboard/API, импорт и бизнес-логика;
- `traffic_hub/` — CRM, PostgreSQL/Alembic, tenant-модели, Redis/worker;
- `dashboard/` — UI, лендинги и assets;
- `codex_gateway/`, `kwork_parser/`, `standalone_content_bot/` — действующие отдельные сервисы;
- `license_auth/`, `license_server/` — совместимость auth/license, Compose использует объединённый `license_gateway`;
- `AccountManager/` — остатки прежнего gateway, не действующее отдельное приложение;
- `tools/windows_license/` — исторический консольный генератор лицензий, перенесён без изменения исходника;
- `tests/`, `deploy/`, `tools/`, `scripts/`, `.github/`, `harness/` — проверки, эксплуатация, сборка и workflow;
- `docs/` — документация продукта; wiki-знания поддерживаются в отдельном `baza`.

Windows EXE остаются в корне по активному launcher/update/installer контракту. Runtime `data/`, `secrets/`, `backups/`, generated `development-imports/` и mutable `harness/state/` не являются исходным кодом и исключены из Git/build context; не удалять их как обычный мусор.

Push в GitHub теперь не запускает production deploy. Оба GitHub deploy workflow ручные; release gate и явный выбор сервисов сохранены. Обычные правки выпускаются напрямую по [[01_Правила/ИИ/Workflow Codex для дебага и разработки]].
