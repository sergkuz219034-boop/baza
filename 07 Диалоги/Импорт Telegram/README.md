# Импорт Telegram

Сюда складываются переведенные в Markdown Telegram-диалоги.

Формат:

- один чат = одна заметка;
- вверху есть метаданные: источник, чат, период, участники;
- ниже идет читаемая переписка по датам;
- сырой HTML-экспорт хранится вне этого контура, в архиве или source workspace.

## Правило

Если нужно разобрать новый Telegram-export, сначала прогоняем его через конвертер, а потом уже дописываем выводы и разборы в отдельные заметки.
