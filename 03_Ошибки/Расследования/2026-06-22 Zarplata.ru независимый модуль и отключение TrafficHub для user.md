# 2026-06-22 Zarplata.ru независимый модуль и отключение TrafficHub для user

## Симптом

Нужно отключить embedded TrafficHub для всех пользователей с ролью `user`, как уже сделано для Account Manager, и довести вкладку `Зарплата.ру` до независимого модуля сбора/выгрузки лидов.

## Зона системы

- `dashboard/index.html`
- `dashboard/app.js`
- `api/routers/zarplata.py`
- `modules/zarplata_api.py`
- `api/routers/jobs.py`
- `traffic_hub/services/job_runner.py`
- `services/leads_service.py`
- `traffic_hub/api/deps.py`

## Гипотеза

Одного скрытия пункта меню недостаточно: роль `user` могла бы дергать `/traffic-api/*` напрямую. Для `Зарплата.ру` ручной `/api/zarplata/search` не равен полноценному модулю, потому что он не проходит через общий job queue и worker.

## Проверка

- Проверен код Account Manager: UI блокируется через `isAdmin()`, backend endpoint `/api/account-manager/token` требует `admin`.
- Проверен TrafficHub API: embedded CRM использует `traffic_hub/api/deps.py`.
- Проверен job контур: команды перечислены в `api/routers/jobs.py` и `traffic_hub/services/job_runner.py`.
- Проверен OpenAPI Зарплата.ру: OAuth2 endpoint `https://api.zarplata.ru/token`, authorize URL `https://hr.zarplata.ru/oauth/authorize`, базовый API `https://api.zarplata.ru`.

## Наблюдение

- До правки `Зарплата.ру` был ручным API-вызовом из UI, без команды job queue.
- В коде был только enum/source mention и новая заготовка router/client; старого рабочего парсера Зарплата.ру не найдено.
- Redirect URI приложения: `https://traffic-hubcrm.ru/auth/callback`.
- Профиль `artem` получил Client ID/Secret/Redirect URI и app-token через `client_credentials`.

## Вывод

Сделано два уровня ограничения TrafficHub:

- UI скрывает/блокирует раздел `TrafficHub` для роли `user`;
- backend `traffic_hub/api/deps.py::require_operator()` для embedded CRM surface теперь требует `admin`.

`Зарплата.ру` переведена в независимый модуль:

- отдельный `modules/zarplata_api.py`;
- отдельный router `/api/zarplata/*`;
- отдельная job-команда `zarplata`;
- запуск через общий queue/worker;
- сохранение лидов в БД и выгрузка в существующие Google Sheets.
