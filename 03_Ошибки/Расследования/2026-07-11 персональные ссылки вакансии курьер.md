# Персональные ссылки вакансии «Курьер»

- Симптом: во вкладке «Вакансии» Operator CRM не было рабочих позиций.
- Зона системы: `operator_crm/index.html`, API настроек и PostgreSQL `control_license_users`.
- Гипотеза: ссылки можно строить динамически по логину, без отдельной копии пользователя.
- Проверка: добавлен `GET /api/settings/operator-vacancies`; он читает всех пользователей и формирует URL Lovko с URL-кодированным `sub1`.
- Наблюдение: Operator CRM — отдельный контейнер; `/api` проксируется Caddy в `autolead_bot`.
- Вывод: вкладка показывает вакансию «Курьер», статус, персональную ссылку и кнопку копирования.
- Следующий шаг: после завершения GitHub CI проверить публичный Operator CRM под операторской сессией.
