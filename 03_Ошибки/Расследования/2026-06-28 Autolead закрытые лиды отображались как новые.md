# 2026-06-28 Autolead закрытые лиды отображались как новые

## Симптом

- В `База лидов` часть строк отображалась как `Новый`, хотя пользователь ожидал, что они уже должны быть отправлены.
- Пример из live: owner `admin`, lead ids `17369`-`17374`, дата лида `25.06.2026`.

## Зона системы

- `services/leads_service.py` — полный цикл Autolead.
- `modules/sheets_sync.py` — выбор строк из основной Google Sheets таблицы.
- `utils/runtime_repository.py` — выдача лидов в UI.
- `utils/runtime_store_pg_leads.py` — PostgreSQL таблица `autolead_leads`.
- Google Sheets основная таблица owner'а.

## Гипотеза

- Лиды не отправляются повторно, потому что уже закрыты в Google Sheets.
- UI показывает `Новый`, потому что не синхронизирует локальный статус лида с результатом отправки/закрытия строки.

## Проверка

- Проверены live PostgreSQL rows `autolead_leads` для owner `admin`, ids `17369`-`17374`.
- Проверена основная Google Sheets таблица admin:
  - pending spreadsheet `1seCE2MPKZV01LJMvL4CuvSDL7IdG-V_vN6hmqoAcZOs`;
  - sheet `Все лиды`.
- Проверен `load_pending_leads_for_send(config)`.
- Проверен код `utils/runtime_repository.py::_decorate_lead_row`.

## Наблюдение

- В Google Sheets у строк уже был непустой `Статус`, поэтому `load_pending_leads_for_send()` корректно не выбирал их для новой отправки.
- Примеры:
  - Антон Медведев Владимирович — `Статус=Отправлено`, офферы `Воксис: Дубль, Onecta #2: Отправлено`;
  - ИВЭНЬ ГАО — `Статус=Отправлено`;
  - Александр Зубенко — `Статус=Отправлено`;
  - Полина Балуева — `Статус=Отправлено`, один оффер с ошибкой;
  - Жасмин — `Статус=Нет номера`.
- В `autolead_send_history` и `autolead_retry_queue` не было записей по этим exact contacts.
- Старый UI-статус считался только по локальной send/retry history, а не по закрытому статусу Google Sheets.

## Вывод

- Ошибка была в отображении и локальном состоянии `autolead_leads`, а не в пропуске отправки.
- Полный цикл правильно пропускал закрытые строки основной таблицы.
- UI был неполным источником правды: он не видел, что Google Sheets уже закрыла строку.

## Исправление

- Product commit: `39fa30a08 fix: mirror autolead delivery status`.
- В `autolead_leads` добавлены поля:
  - `delivery_status`;
  - `delivery_offers`;
  - `delivery_finished_at`.
- После `run_sender(...)` полный цикл теперь owner-scoped обновляет локальные статусы лидов через `mark_lead_delivery_results(...)`.
- `utils/runtime_repository.py` теперь отдаёт UI `delivery_status`, если он уже не `new`.
- Ручной resend очищает `delivery_status`, чтобы строку можно было осознанно переотправить.
- UI получил русские статусы для `no_phone`, `foreign_phone`, `invalid_phone`, `no_offer`, `offer_disabled`, `temporarily_unavailable`, `daily_limit`, `processed`.
