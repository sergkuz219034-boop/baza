# 2026-06-26 одинаковые пресеты офферов для всех пользователей

## Симптом
В модальном окне добавления оффера список `Выбрать из готовых (пресеты)` должен быть одинаковым для всех пользователей. Пользователь ожидал видеть `Onecta #2` в пресетах у всех.

## Зона системы
- UI: `/root/TrafficHub/dashboard/index.html`
- JS: `/root/TrafficHub/dashboard/app.js`
- API персональных офферов: `/api/offers`
- Runtime контейнер: `traffichub_app`

## Гипотеза
Проблема не в owner-scoped `offer_mapping`, а в статическом списке пресетов. `offer_mapping` хранит уже добавленные офферы пользователя, а dropdown пресетов должен быть глобальным справочником.

## Проверка
Код показал:
- dropdown `#om-preset` зашит в `dashboard/index.html`;
- `applyPresetOffer()` только переносит выбранный preset в поля формы;
- `/api/offers` отдаёт персональный `offer_mapping` пользователя.

Live-проверка owner configs показала, что `Onecta #2` есть у нескольких пользователей в `offer_mapping`, но отсутствовал в статическом списке пресетов.

## Наблюдение
Параметры `Onecta #2`, подтверждённые из live config:
- `name`: `Onecta #2`
- `target_url`: `https://tracking.lovko.pro/L6eTlM`
- `platform`: `lovko`

## Вывод
Добавлен глобальный preset `Onecta #2 (lovko)` в `dashboard/index.html`. Теперь dropdown пресетов одинаковый для всех пользователей независимо от их персонального `offer_mapping`.

## Следующий шаг
Если пресетов станет больше, вынести их из HTML в отдельный versioned JSON/endpoint, чтобы не редактировать шаблон вручную.
