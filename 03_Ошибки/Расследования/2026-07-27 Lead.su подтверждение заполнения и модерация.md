# Lead.su: подтверждение заполнения и модерация

## Симптом

TrafficHub писал «успешно заполнен», а в кабинете Lead.su лиды отображались как «В ожидании (обработка)» с нулевой выплатой.

## Зона системы

- Submit Lead.su: `modules/platforms/leadsu.py::LeadsuPlatform.fill`.
- Учёт TrafficHub: `modules/vbiv_bot.py`.
- Postback: `traffic_hub/api/routers/postbacks.py`.

## Гипотеза

Лог TrafficHub может подтверждать только клик submit, но не принятие анкеты партнёром.

## Проверка

27.07.2026 зафиксированы три отправки Тетрики в run log admin. В коде найден fallback: если `_wait_success` не увидел явный success или duplicate, метод всё равно возвращал `FillResult.ok()`.

В кабинете Lead.su записи Voxys уже существуют со статусом «В ожидании (обработка)». Это подтверждает приём лидов партнёркой, но не одобрение и не начисление. На момент проверки postback Тетрики после трёх отправок ещё не поступил.

## Наблюдение

«В ожидании (обработка)» — промежуточный статус модерации Lead.su. Нулевая выплата до решения партнёра нормальна. Старый fallback создавал ложную уверенность именно для случаев без видимого подтверждения формы.

## Вывод

Успех TrafficHub теперь требует явного сигнала партнёрской формы. При его отсутствии возвращается `leadsu: форма не подтверждена после отправки`; запись не считается отправленной и может быть повторена стандартной очередью.

## Следующий шаг

Проверять Тетрику по postback и статусу Lead.su после окна обработки партнёра. Для точной сверки доставки хранить отдельный audit submit с network response/URL без персональных данных.
