# 2026-06-30 content-bot не публикует автопосты

## Симптом

`content-bot` не выкладывал посты автоматически. Дополнительное требование: перед автоматической отправкой сгенерированного поста всегда должна быть кнопка-ссылка на `hrcadry.pro`.

## Зона системы

- `/root/TrafficHub/standalone_content_bot/app.py`
- контейнер `traffichub_standalone_content_bot`
- SQLite `/data/bot.sqlite3`
- таблицы `settings`, `channels`, `generations`, `events`

## Гипотеза

Автопостинг включён глобально, но активный канал не попадает в список scheduled channels из-за пустых настроек темы/расписания.

## Проверка

Проверен live-runtime:

- контейнер `traffichub_standalone_content_bot` был запущен;
- в логах были только старт polling, без ошибок публикации;
- `settings.autopost_enabled = true`;
- активный канал пользователя `934602871` указывал на `channels.id = 26`;
- у канала `#26 HRКадрыPRO` были пустые `topic`, `schedule_times`, `schedule_minutes = 0`.

Функция `list_scheduled_channels()` фильтрует каналы и возвращает только записи, где:

- `is_active = 1`;
- `topic` не пустой;
- задано расписание через `schedule_times` или `schedule_minutes > 0`.

## Наблюдение

Автопостинг не падал. Он не стартовал, потому что активный канал считался ненастроенным для расписания.

Отдельная проблема: первая hotfix-правка текста кнопки через remote shell дала mojibake в Telegram. После этого текст кнопки зафиксирован через unicode-escape, чтобы не зависеть от кодировки Paramiko/PowerShell.

## Вывод

Первопричина отсутствия автопостов — пустая тема и расписание у активного канала.

На сервере сделано:

- для канала `#26 HRКадрыPRO` восстановлены:
  - `topic = вакансии и карьерные возможности`;
  - `schedule_times = 07:00,10:00,15:00`;
- добавлен `build_post_keyboard()`;
- ручная публикация постов и автопостинг теперь добавляют inline-кнопку:
  - `Перейти на сайт`;
  - `https://hrcadry.pro`;
- убран неиспользуемый `style` из Telegram inline button, потому что Telegram Bot API не поддерживает цвет кнопок.

Проверка:

- `python -m py_compile standalone_content_bot/app.py` прошёл;
- контейнер `standalone_content_bot` пересобран и запущен;
- внутри контейнера `build_post_keyboard()` вернул кнопку с текстом `Перейти на сайт` и URL `https://hrcadry.pro`;
- выполнена реальная тестовая автопубликация в `@cadrypro_official`, message_id `119`;
- после теста пользователь удалил тестовый пост.

Кодовый commit: `95c39bd6a Fix content bot CTA button publishing`.

## Следующий шаг

При следующей публикации проверять уже не факт наличия кнопки, а качество текста поста и расписание. Если нужно изменить текст кнопки, делать это через env `CONTENT_BOT_CTA_TEXT`, а не прямой правкой строки через shell с кириллицей.
