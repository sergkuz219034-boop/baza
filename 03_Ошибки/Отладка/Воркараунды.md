# Воркараунды

## Принцип

Воркараунд не равен исправлению. Каждый workaround должен сопровождаться:

- когда применять
- что он не исправляет
- какой следующий инженерный шаг нужен

## Типовые источники

- runtime restart / worker resync
- owner config repair
- cleanup stale state
- redeploy/restart конкретного container contour
