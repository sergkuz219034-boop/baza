## Параллельность, остановка и дрейф релизов — 2026-10-16

1. Параллельность origin не обеспечивает параллельность RU. Проверять весь путь до фактического исполнителя и разделять queue wait/processing. Общий фиксированный пул из четырёх слотов тоже не удовлетворяет требованию независимости всех пользователей. Подтверждённая финальная схема и ограничения: [[02_Код/Сущности/Redis job state]].
2. Отмена своей job является ожидаемым исходом только при совпадении job_id и stop flag; общий catch без этой проверки превращал ручную остановку в ложный job_error. Нельзя скрывать replaced/foreign job и реальные ошибки.
3. Наличие credentials не означает рабочую авторизацию; revoked HH connection нужно переподключить, миграция этого не исправляет. Сбой одного connection не делает остальные нерабочими: [[02_Код/Архитектура/Интеграции]].
4. Проверенный однажды deploy может быть перезаписан последующим образом. 16 октября repo и runtime отчётов различаются: compact/ranking отсутствуют в работающей функции. Проверять hashes и содержимое функций после конечного recreate, сохранять соседние недавние изменения. Причина конкретного перезаписывающего релиза ещё не доказана.
5. Browser fixture и принятие Android job в очередь не доказывают успешное выполнение на физическом телефоне; queued, started и completed должны иметь отдельные доказательства.

### 2026-10-26 — HTTP 401 RU control API при недоступном Redis

Подтверждено в `remote_autolead.verify_request`: подпись с правильным shared key всё равно отклоняется, если Redis не позволяет зарегистрировать nonce; наружу router возвращает 401. В этом инциденте первопричиной был повреждённый хвост Redis AOF, а не HH OAuth. Сначала проверять Redis/nonce store и runtime fingerprint; не перевыпускать HH credentials только из-за control 401. Восстановление: полная проверенная локальная копия, dry-run на копии, сохранение всех завершённых RESP команд, проверка старых очередей перед запуском worker. [[02_Код/Сущности/Redis job state]]. Evidence: `C:/Users/admin/Desktop/Project/outputs/ru-worker-recovery-20261026/EVIDENCE.md`.
