# Graphify: быстрый поиск по wiki и архитектуре

## Назначение

Graphify — первый слой навигации для незнакомого вопроса: он быстро находит связанный кластер заметок Obsidian или файлов кода, чтобы не читать vault и репозиторий подряд. Это «карта перед чтением»: сначала граф и точные поисковые запросы, затем минимальный набор первоисточников.

Подход соответствует принципу, который популяризировал Андрей Карпати для работы ИИ с большими кодовыми базами: не загружать весь контекст, а итеративно извлекать релевантный подграф, проверять его первоисточниками и расширять поиск только при необходимости.

Graphify не является источником истины: любые технические выводы подтверждаются кодом, runtime, БД, конфигом, логами или контейнерами.

## Когда запускать
- в начале задачи, чтобы найти существующие заметки, решения, расследования и плейбуки по теме;
- перед крупным расследованием архитектуры;
- когда нужно быстро найти связи роутера, сервиса и runtime-хранилища;
- когда новый агент должен понять карту проекта без полного чтения всех файлов.

## Цикл поиска

`Запрос → связанный подграф → 2–5 опорных заметок/файлов → первоисточник → уточняющий запрос`

1. Сформулировать вопрос через симптом, сущность и границу: например, `owner settings scheduler`, а не абстрактное `не работает`.
2. Через Graphify и `rg` найти связанные страницы wiki, входные точки кода и обратные ссылки.
3. Прочитать только узлы с максимальной связностью: README раздела, последнее расследование, сущность и релевантный playbook.
4. Проверить утверждения по коду и runtime; пометить устаревшие заметки.
5. Расширять подграф только если первоисточник не объяснил симптом.

## Команды
Локально, из `C:\Users\Арт\Desktop\TrafServer`:

```powershell
graphify update .\remote_files --no-cluster
graphify explain jobs.py --graph .\remote_files\graphify-out\graph.json
graphify explain leads_service.py --graph .\remote_files\graphify-out\graph.json
```

## Правила
- Для wiki сначала использовать Graphify/поиск и Obsidian-ссылки; не читать весь vault последовательным обходом.
- Не коммитить generated graph как архитектурную правду.
- Не использовать старую wiki вместо проверки по коду.
- Если Graphify показывает связь, открыть соответствующий файл и подтвердить поведение.
