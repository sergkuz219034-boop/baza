**Тема**: Масс-найм через классифайд-площадки — Авито, Работа.ру, Zarplata.ru.

## Краткое резюме

Плейбук по работе с досками объявлений как каналом привлечения HR-трафика. Основная идея: доски объявлений — это самый дешёвый CPA-канал для масс-найма при правильной механике выхода на топ, обходе антифрода и выстраивании воронки.

---

## Ключевые блоки

### Выбор площадок
- **Авито Работа**: самый массовый трафик, но высокая конкуренция и агрессивная модерация. Работает через «белые» домены и телефонные номера с историей.
- **Работа.ру / HeadHunter**: дороже, но выше качество соискателя. Используется для продажи «тёплых» лидов.
- **Zarplata.ru**: низкая конкуренция в регионах, хорошая индексация в Яндексе.

### Формулы заголовков
Заголовки объявлений строятся по формуле: **[Должность] + [Конкретная выгода] + [Город/район]**
- Плохо: *«Требуется продавец»*
- Хорошо: *«Продавец-кассир 2/2, 50 000 ₽, выплата еженедельно, Бутово»*

CTR объявления определяют 3 элемента: заголовок, зарплата (от реальной — не звёздочки), первая строка описания.

### Протокол обхода блокировок
1. **Домен**: зарегистрированный от 6+ месяцев, с историей, на реальное ООО/ИП.
2. **Контент**:  уникализировать каждое объявление (перефразирование через ИИ + ручная правка).
3. **Аккаунт**: прогреть через обычные объявления (не HR) перед публикацией вакансий.
4. **Телефон**: виртуальный номер привязывать только через оператора с реальной историей звонков.

### Воронка конверсий
```
Показ объявления → Просмотр → Отклик → Звонок LR → Выезд → Оффер
```
Ключевая метрика: **CAC (Cost per Hire)** — цель до 3 000 ₽ на массовые позиции.
