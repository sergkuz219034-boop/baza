# Антидетект-браузеры: Технический синтез

> Сводный гайд по настройке Dolphin{anty}, AdsPower и Octo Browser для HR-арбитража.

## Сравнительная таблица настроек

| Параметр | Dolphin{anty} | AdsPower | Octo Browser |
| :--- | :--- | :--- | :--- |
| **WebRTC** | Подмена через Fingerprint | 3 режима: Replace, Forward, Disable | Авто-подмена под IP прокси |
| **Прокси** | Вкладка Proxy, формат `ip:port:user:pass` | Менеджер прокси + массовый импорт | Независимый менеджер (Proxies tab) |
| **UDP** | Настраивается в профиле | Можно отключить для стабильности | Опция "Disable UDP" для защиты от утечек |

## Главные правила безопасности
1.  **Гео-соответствие:** Часовой пояс, язык и WebRTC должны строго соответствовать ГЕО вашего прокси.
2.  **Чистка DNS:** Всегда проверяйте на `browserleaks.com`, чтобы DNS не выдавал ваш реальный провайдер.
3.  **Sticky Sessions:** Для работы с аккаунтами классифайдов используйте резидентские прокси со «статичным» IP (хотя бы на 30 минут), а не ротационные.
