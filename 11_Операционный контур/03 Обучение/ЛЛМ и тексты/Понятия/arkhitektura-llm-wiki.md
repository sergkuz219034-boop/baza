# 🏗️ Архитектура LLM Wiki

Система состоит из трёх слоёв. Каждый слой имеет чёткую роль — смешивать их нельзя.

---

## Три слоя

### 1. `Сырье/` — Источники (неизменяемые)
**Кто пишет**: только человек (копирует файлы)
**Кто читает**: LLM (но не изменяет!)

Здесь хранятся все первоисточники:
- Статьи (PDF, markdown)
- Транскрипты подкастов и видео
- Заметки с митингов
- Веб-страницы (через Obsidian Web Clipper)
- Изображения (`Сырье/Ресурсы/`)

> ⚠️ `Сырье/` — источник истины. LLM никогда не редактирует файлы в этой папке.

### 2. `wiki/` — Знания (LLM пишет и поддерживает)
**Кто пишет**: LLM
**Кто читает**: и человек, и LLM

Структурированная, взаимосвязанная коллекция markdown-файлов:

```
wiki/
├── index.md         ← каталог всех страниц
├── log.md           ← хронологический лог
├── overview.md      ← точка входа
├── Понятия/        ← абстрактные концепции, паттерны
├── Сущности/        ← персоны, инструменты, проекты
├── Источники/         ← резюме источников
└── Синтез/       ← анализы, сравнения, выводы
```

Ключевые свойства wiki:
- Перекрёстные ссылки уже проставлены
- Противоречия между источниками уже помечены
- Синтез уже встроен — не нужно делать его заново при каждом вопросе
- **Wiki накапливается** — каждый новый источник делает её богаче

### 3. Schema — Правила (CLAUDE.md / AGENTS.md)
**Кто пишет**: человек + LLM совместно, эволюционно
**Кто читает**: LLM (загружает в начале каждой сессии)

Это файл-конфигурация: как устроена wiki, какие конвенции, какие воркфлоу. Именно он превращает LLM из «болтливого чатбота» в «дисциплинированного хранителя wiki».

---

## Ключевое отличие от RAG

```
RAG:
  вопрос → поиск в Сырье/ → LLM синтезирует ответ → ответ исчезает
  
LLM Wiki:
  источник → LLM компилирует → wiki обновляется (персистентно)
  вопрос → LLM читает wiki → синтезирует ответ → сохраняет в Синтез/
```

В RAG знания добываются заново при каждом вопросе.
В LLM Wiki знания накапливаются и не нужно добывать снова.

---

## Роли

| Роль | Задачи |
|---|---|
| **Человек** | Курировать источники, задавать хорошие вопросы, думать о выводах |
| **LLM** | Всё остальное: суммаризация, перекрёстные ссылки, поддержание консистентности |

*«Вы никогда (или почти никогда) не пишете wiki сами.»* — Karpathy
