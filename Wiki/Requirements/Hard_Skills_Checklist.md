# ✅ Чек-лист проверки Hard Skills

Этот документ используется как зависимость для вакансий при проведении первичного скрининга. Сверяйте навыки кандидата с этими критериями.

## 💻 Общие навыки (Digital)
- [ ] **Работа с CRM**: Понимание логики этапов воронки, умение ставить задачи и писать комментарии.
- [ ] **Google Workspace / Office**: Свободное владение таблицами (ВПР, сводные — для аналитических позиций).
- [ ] **Мессенджеры**: Этикет деловой переписки, быстрые ответы, использование эмодзи (где уместно).

## 💰 Продажи и Клиентский сервис
- [ ] **Отработка возражений**: Не впадает в ступор на "Дорого" или "Я подумаю".
- [ ] **Активное слушание**: Умеет вычленять истинную потребность клиента.
- [ ] **Презентация**: Умеет рассказать о продукте через выгоду для клиента, а не только через функции.

## 🔧 Технические позиции (Мастера/Монтаж)
- [ ] **Наличие инструмента**: Полный комплект для работы (перфоратор, шуруповерт, уровни и т.д.).
- [ ] **Чтение чертежей**: Понимание схем сборки и технических заданий.
- [ ] **Мобильные приложения**: Умение работать с навигацией и отчетностью в смартфоне.

## 📈 Маркетинг и SMM
- [ ] **Копирайтинг**: Умение писать без канцеляризмов и ошибок.
- [ ] **Аналитика**: Базовое понимание охватов, вовлеченности (ER) и конверсий.
- [ ] **Планирование**: Умение работать с контент-планами и отложенным постингом.
