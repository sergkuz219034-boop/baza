# T-Bank Cities

Нормализованная матрица по вакансии `Специалист службы поддержки мобильной связи`.

Источник:
- `Т-Банк HR план_факт + описание (1).xlsx`

Что важно:
- это именно `Т-Мобайл`: чаты плюс входящие звонки
- по текущей матрице здесь `36` региональных строк
- по `Москве` отдельной строки в текущем xlsx для этой вакансии нет
- если кандидат из Москвы, вакансию можно показывать как ближайший релевантный вариант, но без выдуманной суммы
