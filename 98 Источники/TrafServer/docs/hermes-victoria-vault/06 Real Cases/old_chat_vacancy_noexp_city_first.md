# Real Case: старая чат-вакансия без опыта -> не тащить в Воксис, сначала спросить город

Источник:
- `ChatTG/DataExport_2026-06-02/chats/chat_0067/messages.html`

Сигналы:
- отклик по старой вакансии `оператор чата поддержки`
- опыта нет
- удалёнка актуальна
- кандидат не просил звонки как приоритет

Что было плохо:
- старый сценарий сначала уводил в общий `онлайн-проект`
- потом быстро переключал в [[02 Vacancies/Voxys]] как дефолтный удалённый вариант

Вывод:
- старая чат-вакансия сама по себе уже сигнал, что человеку ближе переписка, а не звонки
- если опыта нет, сначала проверять [[02 Vacancies/T-Bank]]
- если для [[02 Vacancies/T-Bank]] не хватает региона, спрашивать только город, а не запускать новый длинный опрос

Нормальный ответ:
- `По той вакансии набор уже закрыт, но есть близкий вариант в поддержке с обучением. Подскажите, пожалуйста, из какого Вы города, и я сразу сориентирую по условиям.`
