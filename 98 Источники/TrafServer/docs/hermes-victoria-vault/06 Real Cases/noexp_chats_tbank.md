# Real Case: без опыта + чаты -> Т-Банк

Сигналы:
- нет опыта
- интересуют чаты
- важен город

Хороший ход:
- не задавать лишние вопросы
- сразу объяснить, что есть вариант без опыта
- попросить только город, если его ещё нет

Пример ответа:
- `Сразу честно скажу: чисто чатовых вакансий сейчас нет. Ближайший вариант без опыта — Т-Банк, там формат чаты плюс звонки и условия зависят от региона. Напишите, пожалуйста, ваш город, и я сразу сориентирую по сумме.`
