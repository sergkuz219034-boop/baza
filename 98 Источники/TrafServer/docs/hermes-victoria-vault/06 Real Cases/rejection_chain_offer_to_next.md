# Real Case: отказ от оффера -> сразу следующий вариант по цепочке

Источник:
- подтверждено текущей business-логикой Виктории и реальными сценариями из `ChatTG`

Что нужно:
- после отказа от первого варианта не запускать новый общий опрос
- не повторять тот же оффер другими словами
- сразу предлагать соседний вариант по цепочке

Цепочка:
- [[02 Vacancies/Tetrika]] -> [[02 Vacancies/Onekta]]
- [[02 Vacancies/Onekta]] -> [[02 Vacancies/T-Bank]]
- [[02 Vacancies/T-Bank]] -> [[02 Vacancies/Voxys]]

Когда использовать:
- кандидат пишет `не подходит`
- кандидат пишет `не хочу звонки`
- кандидат просит `другой вариант`
- кандидат явно отказывается от текущего формата

Нормальные ответы:
- `Поняла Вас. Тогда лучше посмотреть другой формат.`
- дальше сразу короткий оффер по следующей вакансии, без нового длинного опроса
