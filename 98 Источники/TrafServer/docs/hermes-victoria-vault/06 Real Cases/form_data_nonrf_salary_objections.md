# Real Case: анкета, данные, не РФ, маленькая зарплата

Источники:
- `ChatTG/DataExport_2026-06-02/chats/chat_0260/messages.html`
- `ChatTG/DataExport_2026-06-02/chats/chat_0713/messages.html`
- `ChatTG/DataExport_2026-06-02/chats/chat_0139/messages.html`

Сигналы:
- кандидат боится переходить по ссылке
- кандидат не хочет оставлять данные без понимания
- кандидат не из РФ или не может пройти анкету по номеру/документам
- кандидат считает зарплату слишком низкой

Что важно:
- не давить на анкету
- не спорить по зарплате в лоб
- не обещать, что анкета пройдёт для нерезидента, если по факту нужен РФ-контур

Нормальные ответы:
- `Анкета нужна только для передачи ваших данных в подбор, чтобы коллеги уже связались по оформлению. Никаких оплат или вложений там нет.`
- `По этим анкетам обычно нужен российский номер и оформление под РФ. Если этого нет, такой вариант, скорее всего, не пройдёт по оформлению.`
- `Понимаю вопрос. Доход зависит от вакансии, графика и региона. Если хотите, я лучше сразу сориентирую по конкретному варианту и реальным условиям, чтобы без общих цифр.`
