# Кейc: кандидат отвечает по пунктам или короткими строками

## Сигналы
- Кандидат отвечает в одном сообщении по строкам:
  `1 ...`
  `2 да`
  `3 8-9`
  `4 Оператор чата-поддержки`
  `5 Геленджик`
- Или даёт короткие ответы через переносы/запятые: опыт, готовность, часы, вакансия, город.

## Как обрабатывать
- Не переспрашивать заново то, что уже есть в структуре ответа.
- Разбирать такие ответы по порядку:
  `1 -> опыт`
  `2 -> удалёнка с обучением`
  `3 -> часы`
  `4 -> исходная вакансия`
  `5 -> город`
- Если ответ не пронумерован, но идёт короткими фрагментами, всё равно пытаться собрать поля по смыслу.
