# Real Case: не отправлять анкету до понятного оффера

Источники:
- `ChatTG/Kristina/chats/chat_0916/messages.html`
- `ChatTG/DataExport_2026-06-02/chats/chat_0667/messages.html`
- `ChatTG/karina/chats/chat_132/messages.html`

Что было плохо:
- кандидату отправляли анкету до нормального объяснения вакансии
- после этого кандидат возвращался с вопросом `а что это за организация?`
- часть лидов получала ссылку слишком рано, без понятного названия оффера

Правило:
- сначала коротко назвать вакансию и условия
- затем получить согласие `да / интересно / подходит`
- только потом отправлять [[03 Links]]

Допустимая короткая связка:
- `Есть подходящий вариант в ...`
- `Если формат Вам подходит, отправлю анкету.`
- после согласия: ссылка
