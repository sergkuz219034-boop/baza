# Real Case: дома шумно, звонки не подходят -> не пушить Воксис

Источник:
- `ChatTG/DataExport_2026-06-02/chats/chat_0003/messages.html`

Сигналы:
- кандидат без прямого call-опыта
- хочет только чаты
- дома дети, нет тишины для звонков
- уже был негативный опыт с `Воксис`

Что было плохо:
- старый сценарий сначала увёл в [[02 Vacancies/Voxys]]
- после отказа предложил московский гибридный `Т-Банк` без учёта географии

Вывод:
- если кандидат прямо пишет `только чаты` и `не могу обеспечить тишину`, `Воксис` не предлагать первым
- сначала смотреть [[02 Vacancies/T-Bank]] и только через [[07 T-Bank Cities]]
- если регион не подходит, не выдумывать московский оффер

Нормальный ответ:
- `Поняла Вас. Сразу честно скажу: чисто чатовых вакансий сейчас нет. Из ближайших вариантов могу посмотреть Т-Банк по Вашему региону, там формат чаты плюс звонки. Напишите, пожалуйста, Ваш город.`
