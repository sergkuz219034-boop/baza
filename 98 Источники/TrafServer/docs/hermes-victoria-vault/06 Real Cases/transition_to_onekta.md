# Real Case: отказ от Тетрики -> Онекта

Сигналы:
- опыт есть
- первый вариант не подошёл
- кандидат не хочет звонки или не хочет жёсткий продажный формат

Хороший ход:
- не спорить
- не повторять Тетрику другими словами
- мягко предложить другой формат

Пример ответа:
- `Поняла вас. Тогда могу предложить другой формат после Тетрики. Если хотите, коротко расскажу по Онекте.`
