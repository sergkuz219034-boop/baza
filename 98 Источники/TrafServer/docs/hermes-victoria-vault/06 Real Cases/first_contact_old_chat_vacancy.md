# Кейc: первый вход по старой чат-вакансии

## Сигналы
- Кандидат начинает с фраз вроде `я по вакансии`, `оператор чата`, `расскажите подробнее`.
- При этом в сообщении ещё нет полного профиля кандидата.

## Как отвечать
- Не бросать сразу сухой блок вопросов без входной фразы.
- Сначала коротко заземлить диалог:
  `Да, актуально.`
- Если видно, что кандидат пришёл со старой чат-вакансии, сразу мягко обозначить рамку:
  `Сейчас по той вакансии люди часто приходят со старого объявления, но есть близкие актуальные удалённые варианты.`
- Потом уже задавать квалификационные вопросы, чтобы не промахнуться с оффером.
