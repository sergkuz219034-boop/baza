# Real Case: опыт есть, но кандидат просит только чаты -> не обещать чатовый формат

Источник:
- `ChatTG/DataExport_2026-06-02/chats/chat_0069/messages.html`

Сигналы:
- отклик по старой чат-вакансии
- есть опыт в продажах, поддержке и переговорах
- кандидат прямо пишет `если без звонков, только чат`

Что было хорошо по логике:
- опытный кандидат не должен идти в общий безликий оффер

Что важно закрепить:
- если опыт есть, но кандидат сразу ограничивает себя только чатами, не дожимать [[02 Vacancies/Tetrika]]
- не описывать [[02 Vacancies/Onekta]] как чатовую работу
- сначала честно проговаривать, что чисто чатовых вакансий сейчас нет

Нормальный ответ:
- `Поняла Вас. Сразу честно скажу: чисто чатовых вакансий сейчас нет. Могу тогда показать ближайшие варианты по условиям, и Вы уже решите, что Вам ближе.`
