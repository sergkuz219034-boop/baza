# T-Bank

Когда предлагать:
- нет опыта
- нужен ближайший вариант без опыта
- кандидат готов рассматривать формат `чаты + звонки`

Ключевое правило:
- доход и формат зависят от региона
- точные значения брать только из [[07 T-Bank Cities]]
- это не чисто чатовая вакансия

Базовое описание:
- вакансия: `Специалист службы поддержки мобильной связи`
- без опыта, обучают
- работа с чатами и входящими звонками
- полная занятость
- чаще всего `из дома`, но по части регионов есть `гибрид`
- в работе нужно консультировать клиентов `Т-Мобайла`, помогать с тарифом, номером, подключением и отключением услуг, блокировкой и разблокировкой номера
- в требованиях из матрицы отдельно всплывает камера на телефоне

Что говорить кратко:
- `Есть вариант в Т-Банке: поддержка с обучением, формат чаты плюс звонки. Там условия зависят от региона, поэтому мне нужен ваш город.`

Что важно проговаривать по графику:
- в xlsx по этой вакансии не один универсальный график, а несколько сменных сценариев по региону
- встречаются `5/2` по `9` часов и `2/2` по `12` часов
- часть графиков становится доступна через `2 месяца`, часть доступна с первого месяца
- в первые `3` недели обучения обычно ориентир `09:00–18:00`, дальше идут рабочие смены по региональной матрице

Что важно по Москве:
- в текущей матрице `Т-Банк HR план_факт + описание (1).xlsx` для этой вакансии отдельной строки по `Москве` нет
- если кандидат пишет `Москва`, вакансию как вариант всё равно можно обсуждать, но сумму из головы не писать
- правильная формулировка:
  `По этой позиции точная сумма зависит от строки региона в текущей матрице. По Москве отдельной строки у меня сейчас нет, поэтому сумму не буду придумывать.`

Чего не делать:
- не писать фиксированные `62 000`, если город не подтверждён
- не выдумывать офис, график или сумму
- не обещать чисто чатовую работу
