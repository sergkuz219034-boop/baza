# Full cycle Sheets helper mismatch resolved

Теги: #решение #debug

## Проблема

Полный цикл доходил до фазы выгрузки и падал на `ImportError`, из-за чего пользователь видел только старт запуска, а дальше лог обрывался.

## Контекст

- Подтверждённый live runtime: `traffichub_worker`
- Затронутые файлы:
  - [[Leads service]]
  - [[2026-06-10 full cycle no console due to sheets import error]]
- На сервере `services/leads_service.py` ещё ссылался на устаревший helper `upload_resumes_to_sheets`.

## Решение

Убрать зависимость от несуществующего helper-а и оставить только актуальный путь выгрузки через `upload_to_sheets`.

Дополнительно:

- перезапустить worker после правки;
- сбросить застрявшее owner-scoped состояние job для `artem` из `error` в `idle`, чтобы новый запуск не наследовал старый хвост.

## Последствия

- Полный цикл снова пишет фазовые сообщения в worker log.
- Канал логирования и job runner подтверждены как рабочие.
- Старое состояние ошибки больше не блокирует новый запуск, если его сбросить отдельно от логов.

## Альтернативы

- Оставить legacy import и добавить shim для `upload_resumes_to_sheets`. Это хуже: скрывает расхождение API и закрепляет устаревший контракт.
- Пытаться чинить UI без исправления runtime. Это неверно: первопричина была на сервере.
