# 01 Расследования

Сюда попадают отдельные сессии дебага и инженерные разборы.

Правило:

- одна проблема — одна заметка;
- в заметке должны быть симптом, гипотеза, проверка, наблюдение, вывод и следующий шаг.

Что здесь искать:

- свежие баги;
- локализацию причин;
- ход проверки гипотез;
- привязку к коду, логам и runtime.
