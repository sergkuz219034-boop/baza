## Симптом

Пользователь нажимает **Полный цикл**, в UI появляется только старт запуска, но дальнейшие рабочие сообщения не доходят до консоли/лога.

## Зона

- `services/leads_service.py`
- `modules/sheets_sync.py`
- `traffic_hub/services/job_runner.py`
- live runtime worker container

## Гипотеза

Полный цикл доходит до фазы выгрузки, а затем падает на несовместимом импорте внутри `upload_sheets()`. Из-за этого UI не получает ожидаемую последовательность рабочих сообщений.

## Проверка

1. Смотрены live-логи `traffichub_worker`.
2. Найдено повторяющееся падение:
   - `ImportError: cannot import name 'upload_resumes_to_sheets' from 'modules.sheets_sync'`
3. Сверен `services/leads_service.py` на сервере и в рабочем зеркале.
4. Проверен `modules/sheets_sync.py`: актуальный helper называется `upload_to_sheets`, а `upload_resumes_to_sheets` в текущем runtime отсутствует.
5. После фикса и перезапуска worker запущен новый `run` для `artem`; в логах снова появились рабочие фазы:
   - `▶ Фаза 1: Сбор лидов с Rabota.ru`
   - `▶ Фаза 2: Выгрузка в Google Таблицы`
   - `▶ Фаза 3: Рассылка`
6. Для `artem` был сброшен застрявший job state из `error` в `idle`, чтобы новый запуск не жил на старом хвосте.

## Наблюдение

- Сбор лидов проходит успешно.
- Падение происходит именно в `upload_sheets()` после логов о фазе 2.
- Из-за этой ошибки полный цикл не доходит до нормального завершения, а UI остаётся без дальнейших рабочих сообщений.
- После замены импорта и пересборки контейнера worker снова пишет фазовые сообщения в лог, значит канал логирования и job runner рабочие.
- Старое состояние job для `artem` оставалось в `error` после падения; это отдельный operational хвост, а не первопричина сбоя.

## Вывод

Корневая причина была в устаревшем импорте внутри `services/leads_service.py`, а не в кнопке UI и не в websocket-канале.
После исправления worker снова получает и отображает рабочие сообщения полного цикла.

## Следующий шаг

- Держать `upload_sheets()` на единственном актуальном helper-е `upload_to_sheets`.
- Если понадобится отдельная выгрузка резюме, вводить её как отдельный явный pathway, а не через несуществующий legacy-import.
