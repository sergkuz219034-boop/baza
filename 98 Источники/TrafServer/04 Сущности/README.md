# 04 Сущности

Сюда попадают заметки про конкретные модули, сервисы, файлы и хранилища.

Что здесь лежит:

- приложение TrafficHub;
- база данных;
- runtime-компоненты;
- control store;
- сервисные слои и ключевые зависимости.

Правило:

- одна сущность — одна заметка;
- каждая заметка должна ссылаться на код, файл или runtime-факт.
