- Включён ли плагин Obsidian Git
- Есть ли изменения в заметках, которые можно коммитить
- Не открыт ли по ошибке другой vault

## Рекомендуемая простая структура

- `00 Входящие`
- `01 Проекты`
- `02 Работа`
- `03 Обучение`
- `04 Идеи`
- `05 Финансы`
- `06 План`
- `07 Диалоги`
- `08 Архив`
- `99 Вакансии`

## Правило сортировки

- Неясно куда класть -> `00 Входящие`
- Связано с результатом -> `01 Проекты`
- Материал на будущее -> `03 Обучение`
- Идея без действий -> `04 Идеи`
- Не нужно сейчас -> `08 Архив`

## Ежедневное правило

- Все новые мысли сначала писать в `00 Входящие`
- Раз в день разбирать 3-5 заметок
- Раз в неделю чистить входящие
- Не создавать новые папки без необходимости
- Использовать короткие имена файлов
