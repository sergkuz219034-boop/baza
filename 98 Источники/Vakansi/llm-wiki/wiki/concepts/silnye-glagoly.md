# Сильные глаголы

> Глаголы в активном залоге, которые описывают конкретное действие и создают динамику в тексте вакансии.

## Примеры для требований и обязанностей
Вместо вялых конструкций используйте энергичные:

| Вяло | Сильно |
| :--- | :--- |
| Осуществление звонков | Звоните |
| Выполнение плана | Закрываете сделки |
| Ведение отчетности | Пишете отчеты |
| Быть ответственным за... | Отвечаете за... |
| Оказание помощи | Помогаете |

## Почему это работает
Сильные глаголы позволяют соискателю «примерить» на себя роль. Он видит не процесс, а результат и действие.
