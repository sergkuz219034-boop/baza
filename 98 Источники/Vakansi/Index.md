# 🏛 Единая База Рекрутмента (Объединенная)

Добро пожаловать в центральный узел управления рекрутментом. База объединена: здесь собраны операционные процессы, база знаний по вакансиям и инструменты управления.
База `ChatTG` официально встроена в этот vault. Отдельно ее больше не ведем: чатовый слой, экспорты и шаблоны живут здесь же.

## 🧭 Простая структура
- **[[00 Входящие/README|00 Входящие]]** — всё новое и неразобранное.
- **[[01 Проекты/README|01 Проекты]]** — заметки с конкретным результатом.
- **[[02 Работа/README|02 Работа]]** — постоянные рабочие процессы и материалы.
- **[[03 Обучение/README|03 Обучение]]** — обучение и полезные источники.
- **[[04 Идеи/README|04 Идеи]]** — идеи без немедленного действия.
- **[[05 Финансы/README|05 Финансы]]** — деньги, расчёты и планы.
- **[[06 План/README|06 План]]** — день, неделя, месяц, фокус.
- **[[07 Диалоги/README|07 Диалоги]]** — переписки, сценарии и разборы.
- **[[08 Архив/README|08 Архив]]** — всё неактуальное.
- **[[99 Вакансии/README|99 Вакансии]]** — шаблоны и заготовки вакансий.

Правило:

- неясно куда класть -> `00 Входящие`
- связано с результатом -> `01 Проекты`
- материал на будущее -> `03 Обучение`
- идея без действий -> `04 Идеи`
- не нужно сейчас -> `08 Архив`
