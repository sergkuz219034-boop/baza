## 2026-06-30

- Зафиксировано расследование [[2026-06-30 AccountManager telegram dialog split for chats vs content]]: фильтрация Telegram-диалогов разведена по назначению. В `Переписки` остаются только личные `is_user`, а content-runtime `AccountManager` читает только группы и каналы `is_group/is_channel`.
- Зафиксировано расследование [[2026-06-30 AccountManager launch unavailable for tg accounts]]: `Запуск недоступен` у текущих Telegram-аккаунтов был ложным UX-сигналом. На live у аккаунтов валидный `tdata`, но server-side запуск Windows `Telegram.exe/AyuGram.exe` внутри Linux container невозможен, поэтому в `AccountManager` кнопка заменена на рабочие действия `Переписки` и `Почему нет запуска`.
- Зафиксировано расследование [[2026-06-30 AccountManager hidden dialog drawer blocks header buttons]]: часть кнопок `AccountManager` не ломалась по backend, а перекрывалась скрытым drawer Telegram-переписок. В `TrafficHub` live/product repo добавлены `display:none !important` для `.dialog-drawer[hidden]` и `.dialog-drawer-overlay[hidden]`, а также `pointer-events:none` вне `.open`.
