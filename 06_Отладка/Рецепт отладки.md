Главный документ метода отладки для `TrafficHub`.

## Шаг 0. Зафиксировать симптом

- что сломано
- где видно
- для какого owner/user/тенанта

## Шаг 1. Определить зону системы

- web/ui
- API
- auth
- worker
- runtime store
- БД
- интеграция
- host/deploy

## Шаг 2. Проверить runtime

- `api/health`
- контейнеры
- логи
- heartbeat
- runtime файлы
- env/config markers

## Шаг 3. Проверить код

- точку входа
- router/service path
- runtime store boundary
- known invariants
