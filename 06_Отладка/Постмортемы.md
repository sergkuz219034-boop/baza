# Постмортемы

## Что считать постмортемом

- инцидент уже локализован;
- есть подтверждённая первопричина;
- есть выводы по prevention path.

## Минимальный состав postmortem

- симптом и impact
- подтверждённая первопричина
- почему защита не поймала это раньше
- remediation
- prevention / regression test / doc update

## Когда не надо писать postmortem

- если это ещё только гипотеза;
- если нет runtime evidence;
- если это локальная debug-заметка без подтверждённой primary cause.

## Практический переход

- investigation note -> incident trail -> postmortem
- если баг пойман тестом, обязательно указать какой existing или новый test surface это теперь покрывает
