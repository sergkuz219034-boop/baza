# БАГ-018: карточки KPI обновлялись таймером без реальной работы

## Статус

Решено на live-сервере.

## Симптом

После исправления live progress UI начал обновлять карточки лидов каждые 5 секунд во время `running`, даже если реальной работы не происходило.

## Причина

В `dashboard/app.js` был добавлен polling:

- `LAST_DASHBOARD_REFRESH_AT`;
- `loadDashboard()` каждые 5 секунд при `running`.

Это давало визуальное обновление без нового рабочего события и раздражало пользователя.

## Исправление

- Удалён постоянный 5-секундный refresh KPI.
- Добавлен событийный refresh только при рабочих лог-событиях:
  - оффер успешно заполнен;
  - оффер признан дублем;
  - ошибка заполнения;
  - итог рассылки;
  - полный цикл завершён;
  - изменилась обработанная таблица.
- На финише job остаётся финальный refresh карточек и базы лидов.

## Проверка

- В live `/app/dashboard/app.js` отсутствует `LAST_DASHBOARD_REFRESH_AT`.
- Присутствует `LAST_DASHBOARD_EVENT_REFRESH_AT`.
- Контейнер `autolead_server_bot` пересоздан из нового образа.
