# HR Agent Markdown база знаний

## Назначение

Bot-specific источник фактов и сценариев для ответов, квалификации, возражений и повторных касаний Telegram HR Agent.

## Хранение

- Канон шаблона в product repo: `/root/TrafficHub/docs/templates/hr_recruiter_knowledge_base.md`.
- Рабочее значение конкретного бота: `HrAgentChannelBinding.extra_config.knowledge_base_md`.
- Scope: `tenant_id + owner_username + binding id`; база одного бота не должна попадать в контекст другого.
- API-лимит: 30 000 символов.

## Редактирование

AccountManager create/edit modal содержит textarea и импорт `.md`, `text/markdown`, `text/plain`. Загруженный файл читается браузером и отправляется через существующий binding API; отдельного серверного файлового хранилища нет.

## Runtime

`traffic_hub/hr_agent/service.py::_llm_response()` помещает Markdown в защищённый system context после индивидуального промта. База управляет фактами, вопросами, возражениями и follow-up, но не отменяет JSON-контракт, этап воронки и запрет выдумывать неизвестные условия.

## Стартовый шаблон

Содержит:

- известные факты об актуальном предложении;
- алгоритм прямого ответа;
- квалификацию без повторных вопросов;
- библиотеку возражений;
- переход к анкете только после согласия;
- мягкие касания через 24/72 часа;
- контроль повторов и стоп-сигналы;
- запрет давления, выдуманных условий и сбора чувствительных данных.
