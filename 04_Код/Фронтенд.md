# Фронтенд

## Подтверждённый контур

- dashboard HTML/CSS/JS слой живёт рядом с backend web entrypoint;
- часть UI-состояния зависит от websocket и runtime bridge;
- `AccountManager` является отдельным product contour и его нельзя смешивать с основным dashboard.

## Что подтверждено по коду

- frontend entry files:
  - `dashboard/index.html`
  - `dashboard/app.js`
  - `dashboard/style.css`
- `dashboard/app.js` поднимает два разных websocket-канала:
  - `/ws/log`
  - `/ws/status`
- при разрыве `status` websocket UI переключается на polling каждые `5` секунд;
- `log` websocket при разрыве включает history fallback и reconnect;
- `AccountManager` открывается через token bootstrap из `/api/account-manager/token`, а не через прямой shared UI session.

## Log UI boundary

- `appendLog()` нормализует запись, классифицирует level и дедуплицирует обычные log lines;
- `spinner=true` рендерится как отдельная живая строка `.log-spinner`;
- обычный persistent log и transient/spinner поведение нельзя смешивать в одном объяснении бага;
- если проблема только в отображении realtime-лога, надо проверять `dashboard/app.js`, а не сразу storage/runtime.

## Что смотреть первым

1. `connectLogWs()` и `connectStatusWs()` в `dashboard/app.js`
2. token bootstrap для `AccountManager`
3. `appendLog()` / `normalizeLogEntry()` / spinner handling
4. расхождение между websocket-потоком, polling fallback и persisted history

## Navigation invariant

- С 2026-07-02 root route `/` является публичным лендингом TrafficHub, а не CRM shell.
- CRM shell открывается через `/login`, `/dashboard`, `/app` и `/index.html`.
- `dashboard/landing.html` содержит верхнюю навигацию `Главная` / `Wiki` и кнопку `Личный кабинет`; `Wiki` ведёт на product repo `sergkuz219034-boop/TrafficHub`, `Личный кабинет` ведёт на `/login`.
- В hero-блоке лендинга есть CTA `Скачать Setup`, ведущий на `https://github.com/sergkuz219034-boop/TrafficHub/releases/latest/download/SetupTrafficHub.exe`; используется `latest`, чтобы ссылка не требовала правки при каждом новом release.
- `/login` содержит явную кнопку `На главную`, которая ведёт на `/`; это нужно для прямого входа в личный кабинет без потери возврата на публичный лендинг.
- Regression check: `tests/test_landing_routes.py`.
- Fixed commits: `acd0e7a6e`, `ce21f3d19`, `2e369024b`, `9d8073d5b`.
- Вкладка `Вакансии` визуально относится к меню `TrafficHub`, а не к `Autolead`.
- Подтверждено кодом: `dashboard/index.html` содержит `data-crm-hash="vacancies"` и `openCrmSection('vacancies')`.
- Legacy tab id остаётся `vacancies`, потому что экран использует существующий route и загрузчик `/api/offers/vacancies`.
- `/api/offers/vacancies` агрегирует вакансии Rabota.ru и Zarplata.ru; карточки имеют `source` и `source_label`.
- Для Zarplata.ru карточки в этой вкладке read-only: массовые приглашения остаются только для Rabota.ru.
- Regression check: `tests/test_traffic_embedded_auth.py::test_rabota_vacancies_live_under_traffic_menu`.
- Fixed commits: `ec4aa8c16`, `4362d77a4`.

## Audit 2026-06-23

- `dashboard/app.js` остаётся крупным stateful файлом и является регрессионно-опасной зоной для логов, техработ, settings и navigation;
- режим техработ в UI скрывается для admin и должен проверяться на user-contour;
- `AccountManager` для user должен оставаться видимой, но недоступной кнопкой; backend token endpoint `/api/account-manager/token` unauth/user должен возвращать `401/403`;
- root route `/account-manager/` на live даёт `500` из-за ошибки signature в `api/server.py`, это backend bug, а не frontend bug.

## Encoding invariant

- Hardcoded пользовательский текст dashboard должен храниться только в UTF-8.
- Если в UI видны строки вида `Рџ...`, `Рћ...`, `вЂ...`, сначала проверять `dashboard/index.html` и `dashboard/app.js`, а не БД.
- Regression: `tests/test_dashboard_encoding.py` сканирует `dashboard/index.html` и `dashboard/app.js` на типовые mojibake markers.
- Fixed commit: `79c79dbab`.
- 2026-06-29 повторно подтверждено для `dashboard/app.js`, `AccountManager/dashboard/app.js`, `AccountManager/dashboard/index.html`: dirty-state может принести mojibake после ручных UI-правок, поэтому перед commit обязателен grep по `Р`, `вЂ`, `Ð`, `Ñ`.

## Auth token UI invariant

- Frontend не должен хранить bearer token в `localStorage/sessionStorage`.
- CI дополнительно запрещает прямой паттерн `headers.Authorization = ...` в restored TrafficHub SPA.
- Если нужно передать bearer header, использовать проверенный helper/pattern, который не нарушает `tests/test_traffic_embedded_auth.py`.
