# Фронтенд

## Подтверждённый контур

- dashboard HTML/CSS/JS слой живёт рядом с backend web entrypoint;
- часть UI-состояния зависит от websocket и runtime bridge;
- `AccountManager` является отдельным product contour и его нельзя смешивать с основным dashboard.
