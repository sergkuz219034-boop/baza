# Инфраструктура

## Подтверждённые части

- docker-compose product contour
- caddy/public endpoints
- postgres
- redis
- license services
- worker/account_manager containers
- standalone_content_bot
- Telegram HR Agent внутри AccountManager/API

## Удалённые части

- `hermes` удалён из `docker-compose.yml`, Caddy routes, AccountManager UI/API и live Docker runtime 2026-06-30.
- `traffichub_hermes` не должен присутствовать в `docker ps -a`.

## Что это значит для разработки и дебага

- проблема “в приложении” может реально жить в compose/env/container boundary;
- проверка контейнерной карты обязательна перед любыми выводами о поломке бизнес-логики;
- Postgres и Redis являются частью основного operational path, а не вспомогательными сервисами.
- включённые `AUTOLEAD_RUNTIME_*_BACKEND=postgres` определяют production runtime path; при их drift система может стать hybrid без явной ошибки.
- наличие `control.db` на хосте не означает, что основная runtime-нагрузка всё ещё идёт через SQLite.
- worker health на live считается по heartbeat-файлу `/app/data/runtime/worker.heartbeat`, который должен быть моложе `180` секунд.
