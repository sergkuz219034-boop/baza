# Аудит Obsidian vault и Git

Дата: 2026-06-15

## Факты

- Внешняя папка vault: `C:\Users\Арт\Desktop\bazaGIT`
- В ней есть `.obsidian`
- В ней нет `.git`
- Внутри есть вложенная папка `baza`
- В `C:\Users\Арт\Desktop\bazaGIT\baza` есть `.git`, `.obsidian` и `.md`-файлы
- Значит, сейчас Git-репозиторий находится не в корне внешнего vault, а внутри вложенной папки

## Вывод

Obsidian Git будет работать только с тем vault, который открыт как корневой. Если открыт внешний vault, но заметки лежат в `baza/`, синхронизация будет смотреть не туда.

## Текущий правильный вариант

- рабочий vault: `C:\Users\Арт\Desktop\bazaGIT\baza`
- git-репозиторий: в корне `baza`
- плагин `obsidian-git`: должен быть включён именно в `baza\.obsidian`

## Что делать

### Вариант A. Использовать `baza` как настоящий vault

- Открыть в Obsidian папку `C:\Users\Арт\Desktop\bazaGIT\baza`
- Проверить, что там видны `.md`-файлы и `.obsidian`
- Убедиться, что Obsidian Git включён именно в этом vault

### Вариант B. Использовать внешний vault как основной

- Перенести `.md`-файлы из `baza` на уровень выше, в `C:\Users\Арт\Desktop\bazaGIT`
- Убедиться, что рядом с заметками лежит `.obsidian`
- Инициализировать Git именно в корне vault
- Только после этого настраивать Obsidian Git

## Проверка Git

- Есть ли папка `.git` в корне vault
- Если её нет, значит репозиторий ещё не создан
- Если `.git` есть только в подпапке, это отдельный репозиторий, не корень vault

## Рекомендуемая простая структура

- `00 Входящие`
- `01 Проекты`
- `02 Работа`
- `03 Обучение`
- `04 Идеи`
- `05 Финансы`
- `06 План`
- `07 Диалоги`
- `08 Архив`
- `99 Вакансии`

## Правило сортировки

- Неясно куда класть -> `00 Входящие`
- Связано с результатом -> `01 Проекты`
- Материал на будущее -> `03 Обучение`
- Идея без действий -> `04 Идеи`
- Не нужно сейчас -> `08 Архив`

## Ежедневное правило

- Все новые мысли сначала писать в `00 Входящие`
- Раз в день разбирать 3-5 заметок
- Раз в неделю чистить входящие
- Не создавать новые папки без необходимости
- Использовать короткие имена файлов
