# Obsidian Git для команды

Дата: 2026-06-15

## Что хранится в репозитории

- `.obsidian/community-plugins.json`
- `.obsidian/plugins/obsidian-git/`

Это позволяет команде получить одинаково подключённый плагин `obsidian-git` внутри vault.

## Что должен сделать каждый участник

1. Клонировать репозиторий `sergkuz219034-boop/baza`
2. Открыть папку репозитория как vault в Obsidian
3. Убедиться, что на компьютере установлен Git и он доступен из системы
4. Разрешить community plugins в Obsidian
5. Проверить, что плагин `Obsidian Git` включился

## Как синхронизироваться

1. Открыть vault
2. Внести изменения
3. Выполнить команду `Obsidian Git: Commit-and-sync`

## Ограничения

- учётные данные GitHub не хранятся в vault и не синхронизируются через репозиторий
- `workspace.json` не хранится, потому что это локальный файл интерфейса
- если на устройстве нет Git, плагин не сможет пушить и пуллить

## Рекомендуемое правило команды

- использовать один общий репозиторий
- открывать именно корень vault как проект Obsidian
- не редактировать одну и ту же заметку одновременно без договорённости
