# Обзор системы

`TrafficHub` — не one-process и не one-db система.

## Подтверждённые узлы

- web/dashboard/auth/ws: `api/server.py`
- embedded API и router map: `traffic_hub/app.py`
- worker/queue execution: `traffic_hub/worker.py`, `traffic_hub/services/*`
- legacy business execution: `services/*`, `modules/*`, `utils/*`
- infra contour: postgres, redis, worker, account_manager, caddy, license services

## Инварианты

- owner-scoped модель данных и исполнения является частью архитектуры;
- runtime и source repo надо отделять от внешнего wiki-layer;
- любые описания хранилища должны проверяться по live runtime и коду, а не по старым заметкам.
