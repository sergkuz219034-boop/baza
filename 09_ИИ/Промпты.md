# Промпты

- использовать короткие инженерные промпты с явным маршрутом:
  - симптом
  - зона системы
  - проверка
  - наблюдение
  - вывод
  - следующий шаг

- для глубокого system prompt см. [[материалы/документы/legacy-vault/11_Операционный контур/99 Система/Каталог_локальных_wiki_2026-06-16|системные заметки]], если понадобится исторический контекст.
