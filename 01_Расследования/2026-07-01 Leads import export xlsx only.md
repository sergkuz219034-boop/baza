# 2026-07-01 Leads import export xlsx only

## Симптом

Пользователь попросил убрать загрузку и выгрузку CSV: в контуре `База лидов` должен остаться только Excel/XLSX.

## Зона системы

- `api/routers/leads.py`
- `dashboard/index.html`
- `dashboard/app.js`
- `tests/test_leads_excel_io.py`

## Гипотеза

CSV в `База лидов` создаёт лишний форматный контур и мешает унифицировать внешний импорт таблиц. Для текущего продукта достаточно `.xlsx`.

## Проверка

- До правки `api/routers/leads.py` принимал `.csv` и `.xlsx`.
- Был endpoint `GET /api/leads/export.csv`.
- В dashboard были кнопки `Загрузить Excel/CSV`, `Выгрузить Excel`, `Выгрузить CSV`.
- Avito upload имеет отдельный endpoint и не менялся в этой правке.

## Наблюдение

CSV поддерживался только как альтернативный транспорт для `База лидов`; основная таблица и экспорт уже имеют Excel-представление.

## Вывод

Канон для `База лидов`: импорт и экспорт только `.xlsx`. CSV не должен быть доступен в UI и backend для leads import/export.

## Следующий шаг

Если CSV нужно убрать также из Avito upload, делать отдельной правкой, потому что это другой endpoint и другой parser.
