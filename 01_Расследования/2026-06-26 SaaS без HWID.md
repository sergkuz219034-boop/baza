# 2026-06-26 SaaS без HWID

## Симптом

- В проекте оставалась логика активации и загрузки секретов через `HWID`.
- Для серверного SaaS это неверная модель: один сервер обслуживает нескольких пользователей, поэтому привязка аккаунта или интеграций к железу сервера смешивает tenants.

## Зона системы

- `api/server.py::_apply_activate_license_key`
- `tools/activate_license.py`
- `tools/windows_launcher/LicenseKeygen.cs`
- `tools/windows_launcher/TrafficHubActivator.cs`
- `config/settings.py`
- `utils/control_store.py`
- PostgreSQL tables: `control_license_users`, `control_app_configs`, `control_app_auth`

## Гипотеза

- Ошибки изоляции настроек и секретов могут возвращаться, если bootstrap при старте снова подтягивает shared secrets по server `HWID`.
- Для SaaS активация должна работать через `login`, а runtime-секреты должны читаться через owner-scoped settings.

## Наблюдение

- `_apply_activate_license_key` теперь игнорирует legacy `hwid` в ключе и пишет пользователя с пустым `HWID`.
- Auth payload из ключа сохраняется через `control_store.save_user_auth(login, auth)`, а не через `save_auth(hwid, auth)`.
- `activate_license.py` больше не отклоняет ключ как "для другого ПК".
- Windows keygen/activator больше не запрашивает и не показывает `HWID`.
- `config/settings.py` больше не выполняет startup secret sync по `get_hwid()`.
- Legacy hooks `find_users_by_hwid` и `bootstrap_auth_for_hwid` в `control_store` оставлены только как no-op compatibility boundary.

## Вывод

- Подтверждённая модель после фикса: идентичность аккаунта = `login`; настройки и секреты интеграций = owner-scoped; `HWID` не является бизнес-ключом.
- Legacy DB columns/tables могут существовать как compatibility surface, но не должны содержать данные и не должны участвовать в runtime-логике.
- Если будущий код снова вызывает `get_hwid()`, `load_auth_from_cloud(hwid)`, `save_auth_to_cloud(hwid)` или `control_store.save_auth(hwid, ...)` для SaaS-пользователей, это регрессия изоляции.

## Следующий шаг

- При следующей migration pass удалить или переименовать legacy HWID helpers из `utils/license.py`, если будет подтверждено, что внешние keygen/старые операторы больше их не используют.
- Добавить regression check в общий suite: пользовательские настройки Google/Rabota не могут читаться через machine/global key.
