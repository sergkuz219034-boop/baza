# HH admin — догрузка до 504 строк 2026-10-02

Результат: keep. Пользователь разрешил догрузку недостающих откликов через admin по вакансии 137675580, чтобы достигнуть 500 новых строк суммарно.

## Исправление ошибочного вывода

Ранее общий защитный счётчик работодателя трактовался как запрет продолжения через любого менеджера. Это было чрезмерно строгим локальным ограничением, не доказательством исчерпания квоты admin.

Проверка: getcgy654 — manager 16931782, admin — manager 16886797; общий employer 13035389. API показал admin остаток 500 и разрешил GET negotiations по целевой вакансии (200), хотя список активных вакансий admin пуст. Пустой список active сам по себе не доказывает отсутствие доступа к известной вакансии.

Официальный источник: https://hh.ru/article/31102 — суточный лимит указан на одного менеджера. Общедоступные контакты после просмотра одним менеджером могут быть доступны другим; число запросов карточек не обязано совпадать со списанием квоты.

## Выполнение

Одноразовый runner был ограничен этой вакансией, периодом 365 дней и доступными API-коллекциями. Перед открытием карточек исключены 520 ранее известных HH-ID из таблицы, базы и предыдущего журнала просмотров. Для подтверждённого отдельного менеджера создан отдельный атомарный ledger employer+manager; исходный ledger getcgy654 не удалён и не обнулён. Постоянный штатный импорт не переключался на новую схему.

Admin: 54 лида сохранено, 52 новые строки добавлены в настроенную основную таблицу. Импорт остановлен после сохранения текущей партии, когда цель 500 новых строк уже была достигнута; поэтому итог немного выше цели.

Общий результат: 452 предыдущие + 52 admin = 504 новые строки. Число уникальных HH-ID в таблице выросло с 499 перед admin до 551 после него. Итоговый лог: ADMIN_MISSING_DONE saved=54 sheet_added_ids=52 reserved_24h=54.

Контроль после завершения: admin API left=496, локально 54 запроса карточек, operator pause снята только по собственному маркеру, процессы догрузки завершены. App и worker healthy. Дальнейший импорт не запускался. Журнал: data/runtime/hh-admin-missing.log.

## Профилактика

Сверять manager_id и его серверный остаток; не смешивать лимит работодателя, лимит менеджера, число HTTP-запросов и число новых строк. Не обходить исчерпанную квоту переподключением того же менеджера. При запросе догрузки до целевого числа строк учитывать фактически добавленные строки, дубли и размер последней сохраняемой партии.
