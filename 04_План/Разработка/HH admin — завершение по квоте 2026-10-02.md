# HH admin — завершение по квоте 2026-10-02

Результат: keep. Все значения ниже проверены на production, не прогнозы.

По повторному разрешению пользователя импорт admin продолжен за 365 дней по единственной вакансии 137675580, по всем доступным коллекциям переговоров. Ранее известные HH-ID исключались до открытия карточек. Новые аккаунты, переподключения и обход отказов HH не использовались.

## Итог

| --- | ---: | ---: |
| Все проходы getcgy654 | 495 | 452 |

Финальный API admin: limits=500, left=0. Ledger запросов admin: 629. Эти величины не равны: локальный ledger резервирует HTTP-попытки, а HH сообщает собственный остаток менеджера. Корректировки разрешённого числа запросов в одноразовом runner опирались только на свежий ответ quota API и не очищали историю ID. Квота перечитывалась каждые 20 новых карточек; 429 прекращает импорт с сохранением текущей партии.

Уникальных HH-ID в общей настроенной таблице после завершения 1107: 47 существовали до этих проходов, 1060 добавлено. Финальный маркер последнего отрезка: ADMIN_MISSING_DONE saved=66 sheet_added_ids=64 reserved_24h=629; ADMIN_FINAL_QUOTA left=0.

Процесс отсутствует, hh-admin-sheet-buffer.json содержит пустой массив, app/worker healthy, maintenance off. Это завершение **по квоте**, а не доказательство отсутствия других уникальных откликов вакансии. Повторный импорт не запускался.

## Проверенное ускорение

В базе партии по 20 сохранены; Sheets записывался партиями до 60. Между ними использовалась атомарная owner-only серверная очередь с fsync/replace. Тесты без HH: накопление 20+20+20, сохранение после отказа Sheets, восстановление очереди и очистка после успешной отправки.

По явному запросу пользователя последний отрезок запущен с последовательным интервалом 2,5 вместо 3 секунд. На этом отрезке сохранено 66 лидов; частотный 429 не зарегистрирован, остановка произошла при исчерпании квоты. Это ограниченный успешный эксперимент, не гарантия безопасности 2,5 секунды для любых условий. Штатный полный цикл не изменялся.

Первый запуск последнего отрезка завершился timeout при открытии Google workbook, до просмотра новых резюме. После ограниченного повтора открытия и чтения только столбца резюме следующий запуск завершился успешно. Подробный урок: [[../../03_Ошибки/HH — таймаут Sheets до импорта]].

Журналы на сервере: hh-admin-missing.log, hh-admin-all-unique.log, hh-admin-fast-unique.log, hh-admin-pace-trial.log и hh-admin-pace-trial-recovered.log в data/runtime. Ни контакты кандидатов, ни токены в wiki не записаны.
