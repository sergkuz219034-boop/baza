# Архив документов

Этот каталог не является активной wiki.

Здесь допускаются только сырые или вспомогательные документы, которые ещё не были встроены в канонические разделы wiki.

Правила:

- не использовать этот каталог как основную точку входа;
- не хранить здесь дубли канонических страниц;
- после проверки переносить знания в `00_Главная` ... `10_Материалы`;
- legacy-заметки и битые импортированные слои удалены из активного vault.
