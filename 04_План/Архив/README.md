# Архив

Здесь лежат старые расследования, процедуры, решения, сущности и материалы.
Они сохранены, чтобы Codex мог находить доказательства и историю решений, но
не являются стартовой точкой для новой задачи.

## Когда открывать архив

- нужно понять, почему раньше приняли решение;
- текущая проблема похожа на старую;
- профильная страница ссылается на evidence;
- Graphify или поиск нашёл историческую связь.

## Когда не открывать архив

Не начинать с него обычную работу. Сначала открыть [[00_Главное/Главная/Дашборд]], затем
раздел «Сейчас» или профильную техническую страницу.

## Содержимое

- `Исторические расследования` — завершённые исследования.
- `Исторические плейбуки` — прежние процедуры и инструменты.
- `Старые решения` — исторические решения.
- `Старые сущности` — подробные описания прежней модели системы.
- `Старые вакансии` — старые продуктовые материалы.
- `Расследования` — завершённые исследования из прежнего активного слоя.
- `Решения` — решения, поднятые из старого рабочего слоя.
- `Дополнительные материалы` и `Сырые материалы` — импортированные и raw-источники.
