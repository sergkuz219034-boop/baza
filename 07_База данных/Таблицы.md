# Таблицы

## Подтверждённый уровень

Полного каталога PostgreSQL таблиц внутри `baza` нет.

## Что известно

- control/users/config слой уже PostgreSQL-first;
- отдельный `traffic_hub` слой существует;
- Google Sheets не являются заменой DB-таблиц.

## Control store как primary source

- runtime users и app config больше нельзя описывать как данные из одного `control.db`;
- current primary source:
  - `users`
  - `control_user_app_configs`
  - `control_user_app_auth`
  - `control_license_users`
- `CONTROL_DB_PATH=/app/data/runtime/control.db` остаётся migration/fallback артефактом, но не главным источником истины.

## Подтверждённые runtime-зависимости удаления пользователя

- `control_license_users`
- `control_user_app_configs`
- `control_user_app_auth`
- `tenant_memberships`
- `funnels`
- `users`

## Owner-scoped runtime-данные

- `google_sheets.service_account_file` может быть user-scoped;
- runtime-файл сервиса может иметь вид:
  - `/app/data/runtime/secrets/service_account__<username>.json`
- `rabota_ru.proxy_url` хранится в owner app config и может быть причиной runtime-багов даже без проблем в коде.
