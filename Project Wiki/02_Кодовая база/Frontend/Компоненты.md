# Компоненты

## Состояние

`baza` не хранит полный frontend component inventory. Здесь держится только project-level карта.

## Что подтверждено

- UI логов и статусов зависит от websocket/status bridge;
- frontend нельзя дебажить без web/API слоя и worker state.
