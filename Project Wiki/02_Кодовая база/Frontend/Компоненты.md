# Компоненты

## Состояние

`baza` не хранит полный frontend component inventory. Здесь держится только project-level карта.

## Что подтверждено

- UI логов и статусов зависит от websocket/status bridge;
- frontend нельзя дебажить без web/API слоя и worker state.

## Практические узлы

- log/history rendering
- job status pill / run-stop controls
- settings forms для owner-scoped конфигурации
- bridge в Account Manager

## Нетривиальные контракты

- heartbeat не должен копиться как обычная история `app_log`;
- structured log payload нельзя портить frontend-нормализацией `ts`;
- user-facing label оффера не должен деградировать в platform-engine (`tilda`, `lovko`, `leadsu`).
