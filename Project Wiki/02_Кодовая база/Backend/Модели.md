# Модели

## Подтверждённый минимум

- owner-scoped модель проходит через `offers`, `leads`, `finance`, `messengers`, `funnels`, `stats`, `tracking`;
- это подтверждено наличием tenant-isolation теста в live repo.

## Ограничение

Полный каталог доменных моделей нужно наполнять только по live `/root/TrafficHub`, а не из предположений.

## Что уже подтверждено как model-contract

- principal:
  - `username`
  - `role`
- queue/state ownership:
  - `owner`
  - `last_command`
  - `started_at`
  - `finished_at`
- user-scoped sheets bindings:
  - `pending_spreadsheet_id`
  - `pending_sheet_name`
  - `processed_spreadsheet_id`
  - `processed_sheet_name`
