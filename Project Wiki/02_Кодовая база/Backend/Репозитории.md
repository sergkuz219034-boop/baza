# Репозитории

## Канон

- локальный `baza` не является source repo приложения;
- server-side mutable repo находится в `/root/TrafficHub`;
- `baza` хранит только knowledge-layer и ссылки на source of truth.

## Следствие

- любые выводы про backend-репозитории нужно подтверждать live-кодом на сервере, а не только заметками vault.

## Runtime repository boundary

- legacy operational SQLite читается через `utils/database.py`;
- поверх него уже введён boundary `utils/runtime_repository.py`;
- это важный переходный слой между старым storage и новым `traffic_hub` API/CRM контуром.
