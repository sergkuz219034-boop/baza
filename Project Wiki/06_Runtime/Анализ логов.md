# Анализ логов

## Что смотреть

- web/API logs
- worker logs
- Redis owner-state
- websocket/status bridge

## Что считать нормой

- сразу после запуска есть owner-scoped строки `в очереди` и `запущен`;
- для длинной job heartbeat приходит примерно раз в `15` секунд;
- финальный статус должен остаться в истории;
- обычные log lines не должны удалять runtime spinner/status строку.
