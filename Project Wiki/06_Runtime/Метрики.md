# Метрики

## Подтверждённый минимум

В `baza` нет выделенного metrics-каталога. Практический runtime-monitoring пока строится по контейнерам, owner-state и heartbeat.

## Рабочие proxy-метрики

- возраст `/app/data/runtime/worker.heartbeat`
- Redis state owner
- queue length
- число active owners
- status transitions `queued -> running -> idle/error`
