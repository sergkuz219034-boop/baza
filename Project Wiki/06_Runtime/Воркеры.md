# Воркеры

## Подтверждено

- контейнер: `traffichub_worker`;
- модель: subprocess-per-owner;
- stop/progress/state owner-scoped;
- heartbeat хранится в runtime-файле.

## Runtime contract

- busy: `queued`, `running`, `stopping`
- terminal: `idle`, `error`
- stop-path:
  - сначала `request_stop_for_job()`
  - затем event `job_stop_requested`
  - затем `SIGTERM`
  - затем `SIGKILL`, если subprocess не завершился
- stale busy state лечится после ~`6` часов
- default parallel owners на live: `2`

## Для дебага

- compare `/api/jobs/status`, Redis owner state, worker log, web websocket bridge;
- queued без прогресса почти всегда требует проверки `traffichub_worker`;
- restart worker во время активной job может порождать maintenance-ошибки, а не business error оффера.
