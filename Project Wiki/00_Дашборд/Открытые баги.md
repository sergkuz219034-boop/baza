# Открытые баги

## Для этой базы знаний

- legacy-структура vault не project-oriented;
- большая часть заметок живёт вне новой taxonomy-схемы;
- старые внутренние ссылки пока ориентированы на legacy-корни.

## Для TrafficHub

Полный каталог runtime-багов ведётся не здесь, а во внешнем инженерном каноне. Внутри `baza` держать только короткие project-level выводы и ссылки на подтверждённые источники.

## Повторяющиеся проблемные зоны

- owner-scoped queue/status расходится с UI;
- worker/web image drift после rebuild;
- Google Sheets fallback в legacy workbook;
- stop-path и heartbeat regression;
- доступы и auth-flow нельзя объяснять старой one-process моделью.
