# Чек-лист релиза

## Для изменений в `baza`

- проверить, что новые заметки открываются из [[Project Wiki/00_Дашборд/Обзор проекта]];
- проверить, что новые разделы не ломают доступ к legacy-материалам;
- зафиксировать, какие legacy-блоки ещё не разложены по новой схеме.

## Для изменений по TrafficHub

- сначала сверка с live `/root/TrafficHub`;
- затем краткий update блока [[01 Проекты/ТрафикХаб/README|ТрафикХаб]];
- только после этого перенос подтверждённых выводов в `Project Wiki`.

## Для этой wiki

- проверить, что `Index.md` ведёт в [[Project Wiki/README|Project Wiki]];
- проверить, что ключевые страницы архитектуры, runtime, API и DB не пустые;
- не публиковать большие перемещения legacy-дерева без проверки внутренних ссылок.
