# TrafficHub-obsidian

Полный импорт локальной инженерной wiki `TrafficHub-obsidian` в `baza`.

## Назначение

- сохранить весь исторический инженерный канон внутри одной базы;
- не заставлять разработчика ходить в отдельный внешний vault ради полного расследовательского архива;
- оставить `Project Wiki` коротким каноническим входом, а этот раздел использовать как глубокий evidence/archive layer.

## Правило использования

- сначала читать `[[Project Wiki/README|Project Wiki]]`;
- если нужен полный доказательный контекст, проваливаться в этот архив;
- imported archive не считать удобной первой точкой входа, но считать частью канона внутри `baza`.
