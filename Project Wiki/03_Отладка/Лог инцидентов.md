# Лог инцидентов

## Правило

В этот раздел переносить только короткие project-level incident записи, подтверждённые расследованием.

## Пока

Полный incident history в `baza` не нормализован и живёт вне новой структуры.

## Минимальные поля

- дата
- owner
- команда
- контейнеры
- Redis state
- итоговый root cause
