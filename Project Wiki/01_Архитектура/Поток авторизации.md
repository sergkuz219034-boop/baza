# Поток авторизации

## Подтверждённое

- auth не равен core runtime;
- отдельные контейнеры `traffichub_license_auth` и `traffichub_license_server` вынесены из основного web/API слоя;
- Account Manager живёт отдельным приложением на `am.traffic-hubcrm.ru`.

## Реальный auth path

- browser:
  - `POST /auth/login`
  - `POST /auth/logout`
  - `GET /auth/session`
- compatibility:
  - `POST /api/auth/login`
  - `POST /api/auth/logout`
  - `GET /api/auth/session`
  - `GET /api/auth/me`
- session cookie: `traffichub_session`
- fallback для HTTP без session:
  - `authenticate_basic_credentials()`

## Что важно для дебага

- websocket не принимает Basic token как полноценный auth path;
- для `/ws/log` и `/ws/status` нужна browser session;
- helper `check_ws_basic_token()` по сути опирается на session principal, а не на отдельный token flow.

## Следствие

- проблемы логина, лицензий и Account Manager нельзя дебажить как один “общий backend-баг”.
