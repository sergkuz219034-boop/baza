# Страницы

## Подтверждённое

- основной web/dashboard обслуживается контейнером `autolead_server_bot`;
- отдельная standalone SPA-модель `/traffic` считается устаревшей;
- Account Manager — отдельный frontend/app-контур на `am.traffic-hubcrm.ru`.

## Актуальные UI-контуры

- основной dashboard:
  - login/session
  - jobs/status/logs
  - settings
  - leads/offers/debug
- embedded `traffic_hub` UI больше не живёт как отдельная SPA на `/traffic`;
- Account Manager остаётся отдельным приложением со своим frontend и своими role restrictions.

## Что важно для дебага

- проблемы UI статусов почти всегда завязаны на `/ws/status`, Redis state и worker heartbeat;
- проблемы логов нельзя разбирать без связки `app_log` + websocket bridge + frontend normalization;
- если старые заметки говорят про отдельную рабочую SPA `/traffic`, считать их устаревшими.
