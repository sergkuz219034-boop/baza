# Скоринг лидов

Файл: `utils/scoring.py`

## Критерии

| Критерий | Баллы |
|----------|-------|
| Сегодняшний отклик | +30 |
| За последние дни | +10 |
| Совпадение вакансии | +10 |
| Совпадение города | +5 |
| Совпадение пола | +5 |
| Нет телефона | -20 |

## Приоритеты

Лиды сортируются по убыванию баллов. Чем выше — тем раньше обрабатывается:

- Отправка в Playwright
- Приглашение через Rabota.ru
