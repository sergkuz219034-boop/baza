# Мониторинг

## Подтверждённые точки наблюдения

- `docker ps`
- web/API logs
- worker logs
- Redis owner-state
- runtime heartbeat файл worker

## Практический monitoring stack

- health endpoint: `/api/health`
- worker heartbeat:
  - `/app/data/runtime/worker.heartbeat`
- Redis keys:
  - `traffic_hub:jobs:*`
- PostgreSQL runtime/control facts
- Caddy и auth/license контейнеры при edge/login проблемах

## Что считать нормальным минимумом проверки

1. `docker ps`
2. `GET /api/health`
3. `docker logs traffichub_worker`
4. `docker logs autolead_server_bot`
5. Redis owner state
