# Сервисы

## Подтверждённые backend entrypoints

- `/root/TrafficHub/api/server.py`
- `/root/TrafficHub/api/routers`
- `/root/TrafficHub/traffic_hub/app.py`

## Карта слоёв

- `api/server.py`
  - HTML dashboard
  - `/auth/*`
  - `/api/*`
  - `/ws/log`
  - `/ws/status`
  - lifecycle loops вроде `_push_status_loop()` и `_partner_sync_loop()`
- `api/routers/*`
  - `leads`, `jobs`, `stats`, `settings`, `offers`, `system`, `debug`, `avito`, `control`
- `traffic_hub/app.py`
  - embedded router map для `/traffic-api/*`
- `traffic_hub/services/*`
  - `job_queue.py`
  - `job_runner.py`
  - bridge к legacy Autolead runtime
- legacy `services/*` и `modules/*`
  - фактическая business execution логика
  - form fill
  - Rabota / Avito / Google Sheets

## Важные связки

- `api/server.py` <-> `api/ws_manager.py`
- `traffic_hub/worker.py` <-> `traffic_hub/services/job_queue.py`
- `traffic_hub/services/job_runner.py` <-> `modules/vbiv_bot.py`
- `api/authz.py` <-> `api/autolead_access.py` <-> `utils/license.py`
- `traffic_hub/services/autolead_bridge.py` <-> legacy runtime storage
- `utils/runtime_repository.py` <-> верхние read/reset/export path

## Что смотреть первым

- auth/dashboard/websocket слой в `api/server.py`;
- router map в `traffic_hub/app.py`;
- queue/job services в `traffic_hub/services/*`;
- legacy delivery/fill path в `services/leads_service.py` и `modules/vbiv_bot.py`.
