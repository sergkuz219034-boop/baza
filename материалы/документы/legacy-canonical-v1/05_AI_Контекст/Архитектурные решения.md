# Архитектурные решения

## Подтверждённые решения верхнего уровня

- `baza` держать как краткий внешний knowledge-layer;
- полный инженерный канон `TrafficHub` держать отдельно;
- owner-scoped execution и Google Sheets считать инвариантом;
- worker и web дебажить как разные runtime-роли.
