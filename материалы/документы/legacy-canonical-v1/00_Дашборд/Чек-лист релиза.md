- проверить, что новые заметки открываются из [[материалы/документы/legacy-canonical-v1/00_Дашборд/Обзор проекта]];

- сначала сверка с live `/root/TrafficHub`;
- затем update `Project Wiki`;
- при необходимости после этого синхронизация вспомогательного слоя `01 Проекты/ТрафикХаб`.

## Для этой wiki

- проверить, что `Index.md` ведёт в [[README|Project Wiki]];
- проверить, что `Project Wiki` однозначно выглядит как единственная основная wiki;
- проверить, что ключевые страницы архитектуры, runtime, API и DB не пустые;
- не публиковать большие перемещения legacy-дерева без проверки внутренних ссылок.
