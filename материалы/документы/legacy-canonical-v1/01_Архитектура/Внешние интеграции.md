# Внешние интеграции

## Подтверждённые

- Google Sheets как user-scoped data sink/source;
- license auth / license server как внешний auth-контур;
- Account Manager как отдельное приложение;
- домен `traffic-hubcrm.ru` и поддомен `am.traffic-hubcrm.ru`.

## Дополнительно подтверждено

- Rabota.ru:
  - OAuth2
  - signed requests
  - token refresh
- Avito import:
  - CSV/XLSX import path
- partner landing / offer platforms:
  - `lovko`
  - `leadsu`
  - `tilda`
- Caddy как edge proxy между публичными доменами и контейнерами.

## Ограничение

Детальная карта внешних API не живёт в `baza` целиком и должна пополняться только по подтверждённым live-фактам.
