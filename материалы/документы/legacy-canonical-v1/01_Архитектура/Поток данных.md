# Поток данных

## Основные слои

- PostgreSQL: control/users/config и новый `traffic_hub` слой;
- Redis: queue, progress, stop flags, realtime status;
- runtime artifacts: secrets, user config, heartbeat и прочие state-файлы.

## Практический вывод

- система не “чисто PostgreSQL” и не “чисто SQLite”;
- storage model гибридная и требует проверки сразу по БД, Redis и runtime-файлам.
