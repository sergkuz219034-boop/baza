# Обработка очередей

## Подтверждённая модель

- backend очереди: Redis;
- worker model: subprocess-per-owner;
- события и публичный status bridge проходят через web/API слой.

## Ключевые каналы

- `traffic_hub:jobs:queue`
- `traffic_hub:jobs:state:<owner>`
- `traffic_hub:jobs:progress:<owner>`
- `traffic_hub:jobs:stop:<owner>`
- `traffic_hub:jobs:events`
