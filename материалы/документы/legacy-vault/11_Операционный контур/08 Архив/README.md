# 08 Архив

Сюда переносится всё неактуальное:

- старые проекты
- завершённые черновики
- устаревшие заметки

Правило:

- если заметка не нужна сейчас, но её нельзя удалять, отправляй в архив

Что здесь уже лежит:

- `Экспорты/` — старые выгрузки чатов и медиа;
- `Legacy/` — старые корни базы до упрощения структуры.
