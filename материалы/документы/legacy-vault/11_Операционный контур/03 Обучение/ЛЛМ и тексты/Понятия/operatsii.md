# ⚙️ Операции

Три основных действия, которые выполняются с wiki. Все три — инициируются человеком, выполняются LLM.

---

## 1. Ingest — добавление источника

**Когда**: кладёшь новый файл в `Сырье/` и говоришь LLM обработать его.

**Процесс:**
1. LLM читает источник
2. Обсуждает с тобой ключевые выводы
3. Пишет резюме в `Источники/`
4. Обновляет или создаёт страницы концепций (`Понятия/`)
5. Обновляет страницы сущностей (`Сущности/`), если упоминаются
6. Обновляет `Заметки/_index.md`
7. Добавляет запись в `Заметки/log.md`

**Охват**: один источник может затронуть 5–15 страниц wiki — это нормально и хорошо.

**Стиль работы** (выбери свой):
- 🔍 **Вовлечённый**: читаешь резюме, проверяешь правки, направляешь LLM что подчеркнуть
- 🤖 **Автоматический**: скидываешь пачку источников, LLM обрабатывает без надзора

> Рекомендация Karpathy: обрабатывать по одному источнику и оставаться вовлечённым.

---

## 2. Query — вопрос к wiki

**Когда**: хочешь получить ответ, опираясь на накопленные знания.

**Процесс:**
1. LLM читает `Заметки/_index.md`, находит релевантные страницы
2. Читает найденные страницы
3. Синтезирует ответ с цитатами и ссылками
4. **Важно**: если ответ ценный — сохраняет его как новую страницу в `Синтез/`

**Форматы ответов:**
- Markdown-страница (по умолчанию)
- Таблица сравнения
- Слайды (Marp)
- График (matplotlib, mermaid)

> 💡 Хорошие ответы не должны исчезать в чат-истории. Сохраняй их в wiki — так исследования накапливаются так же, как и источники.

---

## 3. Lint — проверка здоровья wiki

**Когда**: периодически, по запросу. По мере роста wiki важно поддерживать её качество.

**Что проверяет LLM:**

| Проблема | Описание |
|---|---|
| Orphan pages | Страницы без входящих ссылок |
| Противоречия | Разные источники утверждают противоположное |
| Устаревшие данные | Новые источники опровергли старые утверждения |
| Пробелы | Концепт упоминается, но страницы нет |
| Сломанные ссылки | Ссылка на несуществующую страницу |
| Разрастание | Страница слишком большая — надо разбить |

**После lint:**
- LLM предлагает новые вопросы для исследования
- Предлагает новые источники для ingest
- Добавляет запись: `## [YYYY-MM-DD] lint | результат`

---

## Сравнение операций

| | Ingest | Query | Lint |
|---|---|---|---|
| **Инициатор** | Человек (добавляет источник) | Человек (задаёт вопрос) | Человек (по расписанию) |
| **Что меняется** | wiki расширяется | wiki расширяется (synthesis) | wiki улучшается |
| **Частота** | При каждом новом источнике | По потребности | Периодически |
