# 🗜️ Компакция — управление ростом wiki

Append-only wiki в итоге превращается в тот же беспорядок, который она должна была заменить. Компакция — ответ на эту проблему.

---

## Паттерн Actuel / Archive

Каждая страница wiki использует разделение на актуальное и архив:

```markdown
## Actuel
- Gemini Flash для отчётов: кредиты Google $2K, ответ 0.4s
- Coolify + Authelia: Pangolin отброшен (конфликт портов, 650MB RAM)

## Archive
- [2026-03] Stripe hosted checkout вместо embedded (белый iframe)
- [2026-03] Отказались от Claude для отчётов (стоимость + задержка)
```

Когда что-то в «Actuel» меняется — старая версия уходит в «Archive» одной строкой с датой. **Ничего не удаляется, только сжимается.**

---

## Правила по типу файла

| Файл | Правило |
|---|---|
| `state.md` | Полная перезапись при каждом обновлении (снимок состояния) |
| `log.md` | Append + компакция (записи >30 дней → одна строка в неделю) |
| Остальные страницы | Паттерн Actuel/Archive |

---

## Лимиты (ориентиры)

Устанавливай максимальную длину файлов — без лимитов через 3 месяца получишь ту же кашу.

| Что | Лимит |
|---|---|
| `index.md` | ~200 строк |
| `log.md` (активная часть) | ~60 строк |
| Любая страница | ~400 строк → разбить |
| Весь `wiki/` одного проекта | ~300 строк (мягкий ориентир) |

---

## MOC — Map of Content

Идея из Zettelkasten: когда 3+ страницы покрывают схожую тему — создай **hub-страницу** (MOC), которая их объединяет.
Например, когда у вас накопится несколько страниц по разным площадкам (Авито, Юла, Работа.ру), создайте [[материалы/документы/legacy-vault/11_Операционный контур/03 Обучение/ЛЛМ и тексты/Синтез/sravnenie-ploshchadok-dlya-hr-arbitrazha|MOC: Площадки]].

**Зачем**: меньше «кликов» между связанными темами. Граф в Obsidian выглядит чище.

---

## Три уровня персистентности

```
CLAUDE.md      → правила (авто-загрузка, стабильный, ~30 строк)
Заметки/state.md  → контекст (читается при старте сессии, перезаписывается)
wiki/*         → глубокие знания (запрашиваются по необходимости)
```

LLM читает `CLAUDE.md` автоматически. `state.md` — по команде. Остальное — только когда релевантно. Это держит расход токенов низким.

---

## Триггер обновления

**Не автоматизируй** обновление wiki. Запускай вручную: `/wiki update` или «обнови wiki».

Автоматизация (например, хук после каждого ответа) срабатывает слишком часто — не каждая сессия достаточно значима, чтобы сохранять контекст. **Ты лучше знаешь**, когда сессия была содержательной.
