# 50 приемов письма (Рой Питер Кларк)

> Письмо как ремесло: набор конкретных инструментов для повышения ясности и силы текста.

## Ключевые приемы для написания вакансий (по Кларку)

1.  **Инструмент №1: Порядок слов (Подлежащее + Сказуемое)**
    *   Ставьте подлежащее и сказуемое в начало предложения. Это делает текст прозрачным и энергичным.
    *   *Пример:* Вместо «У нас в компании для новых сотрудников предусмотрено обучение» пишите «Компания обучает новых сотрудников».
2.  **Инструмент №2: Сильные глаголы**
    *   Используйте активный залог. Глаголы — это мотор текста. Пассивный залог («задачи выполняются») размывает ответственность и звучит скучно.
    *   *Пример для вакансий:* «Вы проектируете системы», а не «Системы проектируются вами».
3.  **Инструмент №3: Осторожно с наречиями**
    *   Наречия часто дублируют смысл глагола или ослабляют его. Если глагол сильный, наречие не нужно.
    *   *Пример:* Вместо «быстро бежать» — «нестись», вместо «внимательно следить» — «контролировать».
4.  **Инструмент №4: Точка как сигнал остановки**
    *   Ставьте важное в конец предложения — там, где читатель делает паузу. Точка придает весу последнему слову.
    *   *Пример:* «Ваш доход составит 200 000 рублей» (акцент на сумме).
5.  **Инструмент №17: Количество элементов (Правило трех)**
    *   Один элемент — для лаконичности. Два — для сравнения. Три — для полноты и ощущения завершенности (идеально для списков обязанностей и бонусов). Четыре и более — создают эффект перечисления и изобилия.
6.  **Инструмент №23: Золотые монеты по пути**
    *   Рассыпайте «вознаграждения» для читателя по всему тексту. В вакансии это могут быть интересные факты о проекте, необычные бонусы или шутки, чтобы удержать внимание до конца.
7.  **Инструмент №44: С мира по нитке (Коллекционирование)**
    *   Собирайте удачные приемы, заголовки и обороты из других вакансий и текстов. Хороший автор — всегда внимательный читатель.
