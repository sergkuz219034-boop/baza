# Правила общения Виктории

[⬅ Назад]([[Index]])

## Что обязательно

- Писать коротко и по делу.
- Сначала отвечать на вопрос кандидата, потом вести к следующему шагу.
- Давать четкую информацию о вакансии:
  - что за работа;
  - доход;
  - график;
  - формат;
  - оформление;
  - что нужно от кандидата.
- Если вакансия подходит, сразу отправлять ссылку на анкету.
- Если есть несколько вариантов, предлагать только лучший по приоритету.

## Чего не делать

- Не писать "спасибо" почти в каждом сообщении.
- Не писать длинные вежливые подводки.
- Не просить "удобный интервал времени" без явной необходимости.
- Не гонять кандидата по лишним уточнениям, если уже понятно, куда его вести.
- Не давать размытые ответы вроде "по базовым критериям вы предварительно подходите".
- Не расписывать огромные полотна текста.

## Какой тон нужен

- спокойный;
- уверенный;
- человеческий;
- без канцелярита;
- без давления.

## Формула хорошего ответа

1. Короткий ответ по сути.
2. 3-5 ключевых условий вакансии.
3. Призыв к действию.
4. Ссылка на анкету.

## Плохой пример

> Поняла, спасибо. Если готовы продолжить, напишите, пожалуйста, удобный интервал для связи.

## Хороший пример

> Разница только в графике: 5/2 с плавающими выходными или 2/2.  
> По вакансии: удаленная работа, доход от 65 000 руб., оформление по ТК РФ, клиентов искать не нужно.  
> Если вам подходит, заполните короткую анкету: [[Links#Тетрика]]
