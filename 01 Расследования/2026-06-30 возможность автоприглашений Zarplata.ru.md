# 2026-06-30 возможность автоприглашений Zarplata.ru

## Симптом

Нужно понять, можно ли добавить автоприглашения через Зарплата.ру по аналогии с Rabota.ru.

## Зона системы

- `modules/zarplata_api.py` — текущий клиент Zarplata.ru.
- `api/routers/offers.py` — общая вкладка вакансий и ручные bulk invites.
- Официальный OpenAPI `https://api.zarplata.ru/openapi/specification/zarplata`.

## Гипотеза

В TrafficHub уже есть чтение откликов/приглашений Zarplata.ru через `/negotiations`, но отправка приглашения может требовать отдельный endpoint и отдельную owner-scoped историю, а не Rabota `invite_history`.

## Проверка

- В live-коде `modules/zarplata_api.py` реализованы `/me`, `/resumes`, `/employers/{employer_id}/vacancies/active`, `/negotiations` и чтение коллекций откликов.
- В `api/routers/offers.py` Zarplata-вакансии выводятся как source `zarplata`, но invite UI помечает их read-only: `Приглашения доступны только для Rabota.ru`.
- `docs/api.md` прямо фиксирует ограничение: отправка приглашений/negotiations через Zarplata.ru API не включена.
- OpenAPI Zarplata.ru подтверждает endpoint `POST /negotiations/phone_interview` — `Пригласить соискателя на вакансию`.

## Наблюдение

`POST /negotiations/phone_interview` принимает form fields:

- `resume_id` — обязательный строковый id резюме;
- `vacancy_id` — обязательный id вакансии;
- `message` — опциональный текст письма;
- `send_sms` — опциональный boolean.

Для шаблонов есть `GET /message_templates/{template}` с `template=invite`, параметрами `resume_id` и `vacancy_id`. Для истории есть `GET /resumes/{resume_id}/negotiations_history`.

## Вывод

Возможность есть на уровне официального API, но в TrafficHub она не реализована. Делать её нужно отдельным контуром Zarplata.ru, а не переиспользовать Rabota `invite_candidate()`.

## Следующий шаг

Если включать автоприглашения Zarplata.ru:

- добавить `ZarplataClient.invite_applicant(resume_id, vacancy_id, message="", send_sms=False)`;
- хранить отдельную owner-scoped историю по ключу `zarplata:resume_id:vacancy_id` или расширить текущую invite history с source/platform;
- использовать `resume_id` из `_source_id` / `_raw_data.external_resume_id` и vacancy id из `_zarplata_vacancy_id`;
- добавить UI-флаг отдельно от Rabota `enable_auto_invite`, чтобы оператор понимал, на какой источник действует автоприглашение;
- перед массовым включением проверить права токена: endpoint может вернуть `403` при отсутствии доступа к платному методу, вакансии или резюме.
