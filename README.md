## Правило канона

- для `TrafficHub` входить только через `Project Wiki` как через главный Obsidian-вход;
- `[[raw/legacy-vault/01 Проекты/ТрафикХаб/README|01 Проекты/ТрафикХаб]]` считать вспомогательным source-layer, а не отдельной wiki;
- обучение, вакансии, диалоги и архивы не считать канонической проектной навигацией для разработки;
- весь этот непроектный слой теперь вынесен в [[raw/legacy-vault/11_Операционный контур/README|11_Операционный контур]].
- полный imported engineering archive теперь лежит внутри `baza`:
  - [[raw/docs/TrafficHub-obsidian/README|TrafficHub-obsidian]]

## Навигационный контракт

- корень vault = единственный основной UX-слой для входа, архитектуры, дебага и runtime-triage;
- `raw/docs/TrafficHub-obsidian` = полный импорт инженерного архива внутри той же wiki;
- `01 Проекты/ТрафикХаб` = вспомогательный source/archive layer с project notes;
- `11_Операционный контур` = все заметки, не являющиеся каноном разработки `TrafficHub`.
