# 01 Проекты

Сюда попадают заметки, которые ведут к конкретному результату:

- активные задачи
- рабочие пакеты
- материалы по текущим запускам

Правило:

- если у заметки есть цель, дедлайн или ожидаемый результат, она живёт здесь
