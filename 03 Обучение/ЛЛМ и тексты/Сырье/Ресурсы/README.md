# Сырье/Ресурсы/

Сюда Obsidian сохраняет изображения из клиппированных статей.

**Настройка**: Settings → Files and links → Attachment folder path = `Сырье/assets`
**Горячая клавиша**: Settings → Hotkeys → "Download attachments for current file" → Ctrl+Shift+D

Эта папка НЕ индексируется LLM как wiki-контент — только как медиа-ресурсы.
