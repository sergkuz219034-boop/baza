# ЛЛМ и тексты

> Персональная база знаний по методу Karpathy.
> LLM пишет и поддерживает. Человек — куратор источников и вопросов.

---

## Быстрый старт

### 1. Открой блок в Obsidian
`File → Open Folder as Vault` → выбери папку `ЛЛМ и тексты/`

### 2. Ознакомься со структурой
- Читай: `Заметки/overview.md` — точка входа
- Каталог: `Заметки/_index.md` — все страницы
- Правила: `CLAUDE.md` — инструкции для LLM

### 3. Добавь первый источник (Ingest)
```
1. Положи файл в Сырье/  (PDF, markdown, текст)
2. Скажи LLM: "Обработай новый файл в Сырье/[имя файла]"
3. LLM обновит wiki автоматически
```

### 4. Задай вопрос (Query)
```
Скажи LLM: "Что в wiki говорится о [тема]?"
LLM прочитает `_index.md`, найдёт страницы и соберёт ответ.
```

### 5. Проверь здоровье (Lint)
```
Скажи LLM: "Сделай lint wiki"
LLM найдёт orphan-страницы, противоречия, пробелы.
```

```

│   ├── overview.md       ← точка входа

├── Источники/            ← резюме источников
├── Стандарты/            ← правила и протоколы
```

## Как работать с LLM

Скопируй `CLAUDE.md` в системный промпт твоего агента (Claude Code, Codex, Cursor и т.д.).

Основные команды:
| Команда | Что происходит |
|---|---|
| `"Обработай Сырье/[файл]"` | Ingest — LLM читает и обновляет wiki |
| `"Что wiki знает о [тема]?"` | Query — синтезированный ответ из wiki |
| `"Сделай lint wiki"` | Lint — проверка здоровья wiki |
| `"Обнови wiki"` | Сохраняет контекст текущей сессии |

## Советы

- 🪨 **Graph View** в Obsidian — лучший способ видеть структуру wiki
- 📎 **Obsidian Web Clipper** — клиппинг статей в `Сырье/` одним кликом
- 🔍 **qmd** — когда wiki вырастет до 100+ источников, добавь поиск
- 📊 **Dataview** — динамические таблицы из YAML frontmatter
- 🗜️ **Компакция** — устанавливай лимиты на размер файлов заранее
