# 🗂️ Индексирование и логирование

Два служебных файла, которые помогают LLM (и тебе) ориентироваться в wiki по мере её роста. Цели разные — не путай их.

---

## index.md — контентный каталог

**Цель**: знать, что вообще есть в wiki.
**Тип**: ориентированный на содержание.

Это каталог всех страниц:
- Ссылка на страницу
- Однострочное описание
- Метаданные (дата, количество источников)
- Организован по категориям

**Как LLM использует index:**
1. При ответе на вопрос — сначала читает index, чтобы найти релевантные страницы
2. При ingest — добавляет новые страницы в нужную категорию
3. При lint — проверяет на orphan-страницы

**Масштабируемость**: работает без embedding-based RAG до ~100 источников и ~сотен страниц. При росте — добавь [[entities/instrumenty|qmd]] для полнотекстового поиска.

**Лимит**: ~200 строк. При превышении — группируй и сжимай.

## log.md — хронологический лог

**Цель**: знать, что и когда происходило с wiki.
**Тип**: append-only, хронологический.

Это журнал событий — никогда не редактируется, только дополняется.

### Формат записи

```
## [YYYY-MM-DD] тип | описание
```

Типы записей:
- `ingest` — добавлен новый источник
- `query` — сохранён ценный ответ
- `lint` — выполнена проверка wiki
- `init` — инициализация vault

### Пример записей

```markdown
## [2026-04-16] ingest | Karpathy LLM Wiki (gist)
Затронуто 8 страниц. Ключевой вывод: wiki vs RAG — принципиально разные подходы.

## [2026-04-16] lint | первичная проверка
3 orphan-страницы исправлены. Добавлены 2 отсутствующих cross-link.
```

### Парсинг лога (unix)

```bash
# Последние 5 записей
grep "^## \[" log.md | tail -5

# Только ingest-записи
grep "^## \[" log.md | grep "ingest"
```

### Компакция лога

Записи старше 30 дней → сжимаются до одной строки в неделю:

```markdown
## [2026-03] неделя 1 | 3 ingest (статьи про трансформеры), 1 lint
```

---

## Ключевое различие

| | index.md | log.md |
|---|---|---|
| **Назначение** | Что есть в wiki | Что происходило с wiki |
| **Структура** | По категориям | По датам |
| **Обновление** | Перезаписывается | Только дополняется |
| **Читает** | LLM при query | Человек для аудита |
| **Лимит** | ~200 строк | Компакция >30 дней |
