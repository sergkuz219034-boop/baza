# raw/

Здесь хранятся все первоисточники. **LLM читает отсюда, но никогда не изменяет.**

## Что сюда класть

- Статьи в формате markdown (через Obsidian Web Clipper)
- PDF-документы
- Транскрипты подкастов / видео
- Заметки с митингов
- Любые текстовые источники

## Workflow добавления источника

1. Скопируй/клиппируй файл в эту папку
2. Скажи LLM: `"Обработай новый файл raw/[имя_файла]"`
3. LLM прочитает, извлечёт знания и обновит `wiki/`

## Важно
мВ
Никогда не редактируй файлы в `raw/` руками после добавления —
это источник истины. Все правки и синтезы идут в `wiki/`.
