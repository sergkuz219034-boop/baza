# 🏠 LLM Wiki — Точка входа

> **Идея в одном предложении**: вместо того чтобы каждый раз искать по сырым документам (RAG), LLM постепенно строит и поддерживает структурированную wiki — персистентный артефакт, который становится богаче с каждым новым источником.

## Ключевые концепции

### [[Понятия/arkhitektura-llm-wiki|Архитектура — три слоя]]
```
Сырье/   ← источники (только чтение)
Заметки/ ← точки входа и лог
schema   ← CLAUDE.md / AGENTS.md: правила для LLM
```

### [[Понятия/operatsii|Три операции]]
- **Ingest** — добавить новый источник, обновить wiki
- **Query** — задать вопрос, получить синтезированный ответ
- **Lint** — проверить на противоречия, orphan-страницы, пробелы

### [[Понятия/pochemu-eto-rabotaet|Почему это работает]]
LLM не скучает, не забывает обновить перекрёстную ссылку, может за один проход затронуть 15 файлов. *Стоимость обслуживания стремится к нулю.*

---

## Отличие от RAG

| RAG | LLM Wiki |
|---|---|
| Ищет в сырых документах каждый раз | Знания компилируются один раз |
| Нет накопления | Артефакт становится богаче |
| Синтез на лету | Синтез уже встроен в структуру |
| Нет перекрёстных ссылок | Ссылки уже проставлены |
| Противоречия не видны | Противоречия помечены явно |

## Инструменты в связке

- **[[Сущности/obsidian|Obsidian]]** — IDE для чтения wiki. Graph View показывает структуру.
- **[[Сущности/instrumenty|Marp]]** — генерация слайдов прямо из wiki-контента
- **[[Сущности/instrumenty|Dataview]]** — динамические таблицы из YAML frontmatter
- **[[Сущности/instrumenty|qmd]]** — локальный поиск по markdown (BM25 + vector)
- **Obsidian Web Clipper** — клиппинг статей в `Сырье/` одним кликом

## Применения метода

- 📖 **Чтение книги** — каждая глава → страницы персонажей, тем, сюжетных линий
- 🔬 **Исследование** — глубокое погружение в тему за недели/месяцы
- 🏢 **Команда** — внутренняя wiki, питаемая Slack-треками, митинг-транскриптами
- 🧘 **Личное** — цели, здоровье, психология, саморазвитие
- 🔍 **Анализ** — конкурентная разведка, due diligence, планирование поездок
