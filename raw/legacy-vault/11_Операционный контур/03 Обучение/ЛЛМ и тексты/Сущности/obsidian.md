# 🪨 Obsidian

Obsidian — это десктопное приложение для работы с markdown-файлами. В системе LLM Wiki играет роль **IDE**: LLM — программист, wiki — кодовая база, Obsidian — редактор.

Сайт: https://obsidian.md

---

## Роль в LLM Wiki

```
LLM пишет wiki  →  Obsidian отображает  →  Человек читает и навигирует
```

В практике Karpathy: LLM открыт с одной стороны, Obsidian — с другой. LLM вносит правки, человек видит результат в реальном времени — движется по ссылкам, смотрит граф, читает обновлённые страницы.

---

## Ключевые функции для LLM Wiki

### Graph View
Лучший способ видеть **форму** всей wiki:
- Какие страницы связаны
- Какие страницы — хабы (много входящих ссылок)
- Какие страницы — orphans (нет входящих ссылок)

> Orphan-страницы — сигнал для lint-операции.

### Wikilinks
Obsidian нативно поддерживает внутренние ссылки формата `[[путь/к/файлу|Название]]`.
LLM должен использовать **полный путь** в ссылках, чтобы избежать «ghost links» (ссылок, создающих пустые файлы в корне).

✅ Правильно: `[[Понятия/arkhitektura-llm-wiki|Архитектура]]`
❌ Неправильно: `[[Понятия/arkhitektura-llm-wiki|architecture]]` (может создать ghost-файл)

## Настройка под LLM Wiki

### Исключение служебных папок из графа

В `.obsidian/app.json` добавь фильтры, чтобы граф показывал только wiki:

```json
"userIgnoreFilters": [
  ".claude",
  "raw",
  "reports"
]
```

Без этого граф превращается в шум из сотен нерелевантных узлов.

### Путь для вложений (изображения)
`Settings → Files and links → Attachment folder path = Сырье/Ресурсы/`

### Горячая клавиша для скачивания вложений
`Settings → Hotkeys → "Download attachments for current file"` → назначь `Ctrl+Shift+D`

После клиппинга статьи — нажал хоткей, все картинки скачаны локально. LLM может смотреть их напрямую.

## Плагины

| Плагин | Назначение |
|---|---|
| **Obsidian Web Clipper** | Конвертирует веб-статьи в markdown одним кликом → в `Сырье/` |
| **Marp** | Генерация слайд-деков прямо из wiki-контента |
| **Dataview** | Динамические таблицы и списки из YAML frontmatter страниц |

## Ограничения

- LLM не может нативно читать markdown с инлайн-картинками за один проход
- Воркараунд: LLM читает текст → затем отдельно смотрит изображения
- Немного неуклюже, но работает достаточно хорошо
