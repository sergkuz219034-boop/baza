# 2026-06-16 Воксис send2.php duplicate и reset формы после AJAX

## Симптом

- `Воксис` в отдельных live прогонах выглядел как “форма не заполнилась” по debug HTML:
  - поля пустые;
  - на странице видны validation labels;
  - success popup визуально не открыт.

## Зона системы

- `modules/platforms/leadsu.py`
- offer `Воксис`
- live artifact `data/debug/debug_Воксис_20260616_020006.html`

## Гипотеза

- Debug HTML для `Воксис` может сниматься уже после AJAX submit и `form.reset()`, поэтому пустые поля и скрытый popup ещё не доказывают runtime failure.

## Проверка

1. Выполнен точечный Playwright probe внутри `autolead_server_bot` по `admin` + первый pending lead.
2. Подтверждён реальный request:
   - `POST https://voxys-rabota.ru/send2.php`
3. Зафиксирован server response:
   - `{"status":"error","message":"Дубль","code":0}`
4. После этого DOM probe показал:
   - `#hidden-content` / `.p_wrapper` содержит текст:
     - `Ваша анкета принята`
     - `Мы свяжемся с вами в ближайшее время`
   - но popup остаётся hidden;
   - поля `#lname/#fname/#phone` уже пустые;
   - классы полей — `valid`;
   - `body_text` снова показывает исходную форму.
5. Возврат платформы:
   - `FillResult(success=True, is_duplicate=True, message="(дубль)")`

## Наблюдение

- Для `Воксис` HTML snapshot после submit легко вводит в заблуждение:
  - форма может быть уже успешно обработана backend-ом;
  - frontend при этом очищает поля;
  - hidden popup с success/duplicate текстом остаётся в DOM, но не всегда показывается визуально.
- Канонический источник истины для `Воксис`:
  1. network request в `send2.php`;
  2. JSON response body;
  3. итоговый `FillResult`;
  4. только потом debug HTML/PNG.

## Вывод

- Пустые поля в `debug_Воксис_*.html` после submit не равны ошибке заполнения.
- На live runtime от `2026-06-16` подтверждён сценарий:
  - submit уходит;
  - backend отвечает `Дубль`;
  - runtime корректно интерпретирует это как duplicate, а не как hard failure.

## Следующий шаг

1. При следующих расследованиях `Воксис` сначала смотреть `send2.php` request/response, а не только HTML snapshot.
2. Если снова появится `leadsu: форма не подтверждена после отправки`, отделять:
   - timeout/blank landing,
   - submit transport error,
   - duplicate JSON response,
   - hidden success popup без network failure.
