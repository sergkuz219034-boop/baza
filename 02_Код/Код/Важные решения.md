# Важные решения

## Подтверждённые решения

- owner-scoped execution вместо global single-flight модели;
- PostgreSQL-first runtime/control contour;
- разделение короткого канона и полного imported archive;
- live runtime важнее устаревших заметок.

## Зафиксированные границы

- `Autolead runtime` и `control_store` нельзя описывать как один storage-layer;
- наличие SQLite-кода в репозитории не равно тому, что production runtime работает на SQLite;
- cleanup remaining SQLite surface должен идти отдельными stream'ами:
  - active runtime fallback
  - hybrid read/metrics
  - separate control contour
  - test-only fixtures
- live `control_store` на `2026-06-17` уже `backend=postgres`, даже при существующем `control.db`:
  [[04_План/Материалы/сырьё/документы/TrafficHub-obsidian/01 Расследования/2026-06-17 Live control_store backend]]
