# Offer Presets

## Назначение
Offer presets — глобальный справочник готовых офферов в модальном окне добавления оффера Autolead.

## Подтверждённые факты
- Список пресетов находится в `/root/TrafficHub/dashboard/index.html`, select `#om-preset`.
- Функция `applyPresetOffer()` находится в `/root/TrafficHub/dashboard/app.js`.
- Пресет только заполняет поля формы: название, URL, platform.
- Сохранение оффера идёт в `/api/offers` и записывает результат в персональный `offer_mapping` пользователя.

## Важное разделение
- `preset` — общий шаблон, одинаковый для всех пользователей.
- `offer_mapping` — персональный список уже сохранённых офферов пользователя.

## Текущий вывод
Если пользователь не видит оффер в dropdown пресетов, проблема в глобальном HTML-списке. Если пользователь не видит оффер в таблице офферов, проблема в его `offer_mapping`.
