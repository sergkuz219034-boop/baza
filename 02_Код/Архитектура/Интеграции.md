## Product integrations contour

- `traffic_hub/api/routers/integrations.py`
- router живёт на `prefix="/traffic-api/settings/integrations"`
- `NetworkIntegration` хранит status, credentials, postback token и sync state
- `control_store` участвует как user-config layer для integration credentials
- postback token generation подтверждён для `leadsu` и `pampadu`

## Legacy operational contour

- `services/leads_service.py` продолжает вести operational full-cycle через `Rabota.ru` и `Google Sheets`
- `modules/rabota_api.py`:
  - получает credentials из общего owner-scoped encrypted repository
  - без owner не читает общий token file; leased credentials только в памяти
  - refresh выполняет общий lifecycle, сетевые запросы через RU
- `modules/sheets_sync.py`:
  - держит pending/processed queue bindings
  - умеет читать offers из Google Sheets и dedupe с Rabota vacancies

## Import и bridge contour

- `api/routers/avito.py` + `modules/avito_import.py`:
  - Avito здесь живёт как import path, а не как постоянный realtime API
  - импортированные строки нормализуются и грузятся в Google Sheets
- `api/routers/control.py`:
  - `POST /import-legacy-sheets` импортирует legacy Google Sheets data в `control_store`
- `AccountManager` bridge живёт отдельно через `/api/account-manager/token`

## Что не смешивать

- product `traffic_hub` integrations и legacy Rabota/Sheets path
- postback contour и import contour
- `AccountManager` bridge и partner/network integrations
